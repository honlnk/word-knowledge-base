# transmit

## 基本信息

- **发音**: /trænzˈmɪt/ (英式) /trænzˈmɪt/ (美式)
- **词性**: 动词 (verb) - 及物和不及物
- **来源**: 拉丁语 transmittere (送过去、送穿过）

> [!tip] 栟心记忆
> **transmit = 送过去、传送**
> - trans- (across) + mit (send) = send across
> - 从一边送到另一边 = 传输、传播

---

## 核心含义

### 动词 (v.)

**传输、传播、传导**

### 基本含义

1. **传输、传送**
   - 通过渠道或介质传送某物
   - **Transmit** data via satellite.（通过卫星传输数据）
   - The station **transmits** radio signals.（电台传输无线电信号）

2. **传播、播送**
   - 播送或传播信息、节目
   - The channel **transmits** news.（频道播送新闻）

3. **传达、传染**
   - 传播疾病、思想或品质
   - **Transmit** knowledge to students.（向学生传授知识）
   - Mosquitoes **transmit** malaria.（蚊子传播疟疾）

4. **传导**
   - 传导热、光、声音等
   - Glass **transmits** light.（玻璃传导光线）

> [!example] 常见用法
> ```
> **transmit something** (传输某物)
> **transmit to** (传输给)
> **be transmitted by** (通过...传输)
> **be transmitted to** (被传输到)
> ```

## 🔬 词源分析

### 构词结构

```
transmit = trans- + mit + t
```

**构词解析**：
transmit 来自拉丁语 **transmittere**（送穿过），由以下部分组成：
- `trans-` 前缀表示"across, through"（穿过、通过）
- `mittere` 词根表示"to send, to let go"（送、让过）
- 动词结尾表示现在时
- 整体含义是"send across"→"send through"→"transmit/transport"

### 构词拆解

```
transmit = trans- + mittere + (动词结尾)
              ↓
   trans- (across) + mittere (to send/let go)
              ↓
      "to send across" → "to send through"
              ↓
         transmit (传输、传播)
```

### 词源演变路径

```
拉丁语: transmittere (to send across)
    ↓
古法语: transmettre
    ↓
英语 (16世纪): transmit
现代义: "传输、传播、传导"
```

### 🔤 词根详解：mit- / miss-

**什么是 mit-/miss-？**

- **来源**：拉丁语 **mittere** (to send, to let go)
- **含义**：送、派、让过
- **频率**：**非常重要的词根！** 技术英语中非常常见

#### 核心含义：send = let go

```
送 → 让过
  ↓
送过去 → 传输
送出去 → 发出
送上去 → 提交
```

> [!info] 关键规律
> **动词用 mit-，名词用 miss-**
> ```
> transmit (动词)   →   transmission (名词)
> permit (动词)   →   permission (名词)
> admit (动词)    →   admission (名词)
> submit (动词)   →   submission (名词)
>
> 为什么？因为 mittere 的过去分词是 missum
> ```

## 🌿 词根家族：mit- / miss-

都来自拉丁语词根 **mittere** (to send, to let go)：

| 单词 | 构词 | 含义 | 记忆提示 |
|:-----|------|------|----------|
| **permit** | per- (through) + mit | 允许、许可 | 让...通过 |
| [[permission]] | per- + miss + -ion | 许可、准许 | 让通过的名词 |
| [[admit]] | ad- (to) + mit | 承认、准许进入 | 让进入 |
| **admission** | ad- + miss + -ion | 承认、入场费 | 让进入的名词 |
| **submit** | sub- (under) + mit | 提交、屈服 | 送交下面 |
| **submission** | sub- + miss + -ion | 提交、服从 | 送交的名词 |
| **transmit** | trans- (across) + mit | 传输、传播 | 送过去 |
| **transmission** | trans- + miss + -ion | 传输、传播 | 送过去的名词 |
| **emit** | e- (out) + mit | 发出、发射 | 送出 |
| **emission** | e- + miss + -ion | 发射、排放 | 送出的名词 |
| **dismiss** | dis- (away) + miss | 解散、驳回 | 送走 |
| **mission** | miss + -ion | 任务、使命 | 被派出的 |
| **commit** | com- (together) + mit | 委托、承诺 | 一起送 |
| **commission** | com- + miss + -ion | 委员会、委托 | 被委托的任务 |
| **remit** | re- (back) + mit | 汇款、宽恕 | 送回 |
| **remission** | re- + miss + -ion | 缓解、汇款 | 送回的结果 |
| **intermit** | inter- (between) + mit | 暂停、间断 | 中间送 |
| **intermission** | inter- + miss + -ion | 间歇、幕间休息 | 中间的间隔 |
| **omit** | o- (out) + mit | 省略、遗漏 | 送出去 |
| **omission** | o- + miss + -ion | 省略、遗漏 | 被省略的 |

> [!tip] 词根记忆规律
> ```
> 动词多用 mit-：permit, admit, submit, transmit, emit
> 名词多用 miss-：permission, admission, submission, transmission
>
> 例外：mission 本身就是名词 (被派出的东西)
>       dismiss 本身就是动词 (用 miss)
> ```

## ⚠️ 常见错误与注意点

### 错误1：混淆 transmit 和 transfer

```
❌ Use transmit for file transfer
✓ transfer = 从一处移到另一处（通常物理移动）
✓ transmit = 通过介质传送（强调过程）

Transfer file to USB.（把文件转移到USB）
Transmit data over network.（通过网络传输数据）
```

### 错误2：介词搭配错误

```
❌ transmit something with cable
✓ transmit something via cable（通过电缆传输）
✓ transmit by cable（用电缆传输）

via 是技术场景中最常用的介词
```

### 错误3：名词形式错误

```
```
❌ transmition
✓ transmission

规律：mit- (动词) → miss- + -ion (名词)
```
