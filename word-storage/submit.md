# submit

## 基本信息

- **发音**: /səbˈmɪt/ (英式 & 美式)
- **词性**: 动词 (verb) - 及物和不及物
- **来源**: 拉丁语 submittere (送下去、送交下面）

> [!tip] 核心记忆
> **submit = 送交下面、交上去**
> - sub- (under) + mit (send) = send under
> - 放到下面 → 提交、屈服

---

## 核心含义

### 动词 (v.)

**提交、呈交、屈服**

### 基本含义

1. **提交、呈交**
   - 把某物交给某人或组织考虑/决定
   - **Submit** the application form.（提交申请表）
   - **Submit** a paper to the journal.（向期刊提交论文）

2. **屈服、顺从**
   - 顺从某人的权威或意见
   - Refuse to **submit** to blackmail.（拒绝屈服于勒索）
   - He refused to **submit** to their demands.（他拒绝屈服于他们的要求）

3. **建议、主张**
   - 提出某事供考虑（正式用法）
   - I **submit** that this is the best solution.（我主张这是最好的解决方案）

> [!example] 常见用法
> ```
> **submit something to** (把...提交给)
> **submit to something** (屈服于)
> **submit that** (主张、建议)
> **be submitted for** (被提交用于)
> ```

## 🔬 词源分析

### 构词结构

```
submit = sub- + mit + t
```

**构词解析**：
submit 来自拉丁语 **submittere**（送下去），由以下部分组成：
- `sub-` 前缀表示"under, below"（下面、底下）
- `mittere` 词根表示"to send, to let go"（送、让过）
- 动词结尾表示现在时
- 整体含义是"send under"→"send down"→"put under authority"→"屈服/提交"

### 构词拆解

```
submit = sub- + mittere + (动词结尾)
            ↓
   sub- (under) + mittere (to send/let go)
            ↓
      "to send under" → "to send down"
            ↓
      "to put under authority" → "submit/yield"
            ↓
         submit (提交、屈服)
```

### 词源演变路径

```
拉丁语: submittere (to send under)
    ↓
古法语: soumettre
    ↓
英语 (15世纪): submit
现代义: "提交、屈服、顺从"
```

### 🔤 词根详解：mit- / miss-

**什么是 mit-/miss-？**

- **来源**：拉丁语 **mittere** (to send, to let go)
- **含义**：送、派、让过
- **频率**：**非常重要的词根！** 技术和学术英语中都很常见

#### 核心含义：send = let go

```
送 → 让过 → 交上去
  ↓
交到下面 → 放到权威之下 → 屈服
送上去 → 提交文件/作业
```

> [!info] 关键规律
> **动词用 mit-，名词用 miss-**
> ```
> submit (动词)   →   submission (名词)
> admit (动词)   →   admission (名词)
> permit (动词)  →   permission (名词)
> transmit (动词) →   transmission (名词)
>
> 为什么？因为 mittere 的过去分词是 missum
> ```

## 🌿 词根家族：mit- / miss-

都来自拉丁语词根 **mittere** (to send, to let go)：

| 单词 | 构词 | 含义 | 记忆提示 |
|:-----|------|------|----------|
| **permit** | per- (through) + mit | 允许、许可 | 让...通过 |
| [[permission]] | per- + miss + -ion | 许可、准许 | 让通过的名词 |
| [[admit]] | ad- (to) + mit | 承认、准许进入 | 让进入 |
| **admission** | ad- + miss + -ion | 承认、入场费 | 让进入的名词 |
| **submit** | sub- (under) + mit | 提交、屈服 | 送交下面 |
| **submission** | sub- + miss + -ion | 提交、服从 | 送交的名词 |
| **transmit** | trans- (across) + mit | 传输、传播 | 送过去 |
| **transmission** | trans- + miss + -ion | 传输、传播 | 送过去的名词 |
| **emit** | e- (out) + mit | 发出、发射 | 送出 |
| **emission** | e- + miss + -ion | 发射、排放 | 送出的名词 |
| **dismiss** | dis- (away) + miss | 解散、驳回 | 送走 |
| **mission** | miss + -ion | 任务、使命 | 被派出的 |
| **commit** | com- (together) + mit | 委托、承诺 | 一起送 |
| **commission** | com- + miss + -ion | 委员会、委托 | 被委托的任务 |
| **remit** | re- (back) + mit | 汇款、宽恕 | 送回 |
| **remission** | re- + miss + -ion | 缓解、汇款 | 送回的结果 |
| **intermit** | inter- (between) + mit | 暂停、间断 | 中间送 |
| **intermission** | inter- + miss + -ion | 间歇、幕间休息 | 中间的间隔 |
| **omit** | o- (out) + mit | 省略、遗漏 | 送出去 |
| **omission** | o- + miss + -ion | 省略、遗漏 | 被省略的 |

> [!tip] 词根记忆规律
> ```
> 动词多用 mit-：permit, admit, submit, transmit, emit
> 名词多用 miss-：permission, admission, submission, transmission
>
> 例外：mission 本身就是名词 (被派出的东西)
>       dismiss 本身就是动词 (用 miss)
> ```

```
sub- (under, below) + mit (send) = send under
      ↓
   送到下面 → 交到权威之下
      ↓

### 方法2: 场景联想法

```
场景1：交作业
→ **Submit** your assignment by Friday.
→ 在周五之前提交作业
→ 把作业送到老师那里（上面的人）

场景2：屈服于压力
→ Refuse to **submit** to pressure.
→ 拒绝屈服于压力
→ 不让自己"放在"压力之下

场景3：提交申请
→ **Submit** the application online.
→ 在线提交申请
→ 把申请文件送出去
```

### 方法3: 对比记忆法

```
submit vs surrender vs yield

submit     提交/屈服（正式，可以是自愿的）
surrender  投降（战争，彻底放弃抵抗）
yield       让步、屈服（部分妥协）

He submitted to the examination.（他提交了考试）
He surrendered to the enemy.（他向敌人投降）
He yielded to pressure.（他在压力下让步了）
```

## ⚠️ 常见错误与注意点

### 错误1：混淆 submit 和 surrender

```
❌ Use submit for war surrender
✓ surrender = 投降（军事、彻底）
✓ submit = 提交/屈服（更广泛，可以自愿）

The army surrendered.（军队投降了）
The student submitted to the test.（学生参加了考试）
```

### 错误2：介词搭配错误

```
❌ submit something for to teacher
✓ submit something to teacher（提交给某人）
✓ submit to authority（屈服于权威）
```

### 错误3：名词形式错误

```
❌ submition
✓ submission

规律：mit- (动词) → miss- + -ion (名词)
```
