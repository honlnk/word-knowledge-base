# convert

## 基本信息

- **发音**: /kənˈvɜːt/ (英式 & 美式)
- **词性**: 动词 (verb) - 及物和不及物
- **来源**: 拉丁语 convertere (完全转变)

---

## 核心含义

### 动词 (v.)

**转换、改变、使转变**

表示将某物从一种形式、状态或用途转变成另一种。

> [!tip] 核心记忆
> **convert = 完全地转动、彻底地改变**
> - 动词形式，强调"动作"
> - 不是小改动，是彻底转变

### 基本含义

1. **转换、转变（形式）**
   - 从一种形式变成另一种
   - Convert water into steam (把水变成蒸汽)

2. **改变信仰**
   - 宗教或观点的改变
   - Convert to Christianity (改信基督教)

3. **换算**
   - 数值或单位的转换
   - Convert pounds to kilograms

4. **改造、改建**
   - 改变建筑物的用途
   - Convert the garage into a studio (把车库改成工作室)

> [!example] 常见用法
> ```
> **convert to** (转换成)
> **convert into** (转变成)
> **convert from** (从...转换)
> **be converted to** (被转换成)
> ```

## 🔬 词源分析

### 构词结构

```
convert = con- + vert + t
```

**构词解析**：
convert 来自拉丁语 **convertere**（完全转动），由以下部分组成：
- `con-` �前缀表示"完全、彻底"（com- 的变体，在 v 前变成 con-）
- `vertere` 词根表示"转动、转变"
- 动词结尾 `-t` 来自拉丁语第一变位动词
- 整体含义是"彻底转动"→"完全转变"

### 构词拆解

```
convert = con- + vertere + (动词结尾)
             ↓
   con- (completely) + vertere (to turn)
             ↓
      "to turn completely" → "to transform"
             ↓
         convert (完全转换的动作)
```

### 词源演变路径

```
拉丁语: convertere (to turn completely)
    ↓
古法语: convertir / converti
    ↓
英语 (13世纪): convert
现代义: "转换、改变信仰"
```

### 🔤 词根详解：vert- / vers-

**什么是 vert-/vers-？**

- **来源**：拉丁语 **vertere** (to turn, to rotate)
- **含义**：转动、转变、改变方向
- **频率**：**非常重要的词根！** 在英语中出现频率极高

#### 核心含义：转动 = 转变

```
物理转动 → 抽象转变
  ↓
方向改变 → 观点改变
状态改变 → 形式改变
```

> [!info] 重要区别
> **convert（动词）vs. conversion（名词）**
> ```
> convert = con + vert + t (有 t)
> conversion = con + ver + sion (t 消失，用 -sion 替代)
>
> 这是因为动词→名词的形态变化中，t 被省略了
> ```

## 🌿 词根家族：vert- / vers-

都来自拉丁语词根 **vertere** (to turn)：

| 单词 | 构词 | 含义 | 记忆提示 |
|:-----|------|------|----------|
| **convert** | con- (完全) + vert | 转换、改变信仰 | 完全转动（动词） |
| [[conversion]] | con- + vers + -ion | 转变、转换 | 转动的名词形式 |
| **divert** | di- (away) + vert | 转移、消遣 | 转向别处 |
| **diversion** | di- + vers + -ion | 转移、娱乐 | 转移注意力 |
| **invert** | in- (into) + vert | 使颠倒、反转 | 向里翻转 |
| **inversion** | in- + vers + -ion | 倒置、反转 | 倒转的状态 |
| **revert** | re- (back) + vert | 恢复、回到 | 转回去 |
| **reversal** | re- + vers + -al | 颠倒、反转 | 转回去的动作 |
| **adversary** | ad- (against) + vers + -ary | 对手、敌手 | 转向对立面 |
| **adverse** | ad- + verse | 不利的、相反的 | 转向对立的 |
| **reverse** | re- (back) + verse | 颠倒、相反 | 转向反方向 |
| **versatile** | vers + -atile | 多才多艺的 | 能多方向转动的 |
| **version** | vers + -ion | 版本、译本 | 转变出来的形式 |
| [[conversation]] | con- + vers + -ation | 对话、交谈 | 一起转变（思想） |
| **introvert** | intro- (向内) + vert | 内向的人 | 转向自己 |
| **extrovert** | extro- (向外) + vert | 外向的人 | 转向外部 |

> [!tip] 词根记忆规律
> ```
> 动词多用 vert-：convert, divert, invert, revert
> 名词多用 vers-：conversion, diversion, inversion, version
>
> 注意：convert 和 conversion 的变化
> convert (有 t) → conversion (t 消失，加 -sion)
> ```

## ⚠️ 常见错误与注意点

### 错误1：混淆 convert 和 change

```
❌ Use convert for any change
✓ convert = 彻底的转变（形式、性质、信仰）
✓ change = 任何改变（大小皆可）

convert 暗示性质或本质的改变
change 可以是表面的、微小的改变
```

### 错误2：动词用法错误

```
❌ convert the file with Word
✓ convert the file to Word format

❌ conversion the file to PDF
✓ convert the file to PDF (动词用 convert，不是 conversion)
```

### 错误3：拼写错误

```
❌ conversin (少了 o)
❌ convertion (t 不应该存在)
✓ convert (动词，有 t)
✓ conversion (名词，没有 t)
```

## 💼 同义词辨析

### 表示"改变、转换"的动词

| 单词 | 侧重点 | 使用场景 | 例句 |
|:-----|--------|----------|------|
| **convert** | 彻底转变 | 形式、性质、信仰 | Convert to digital format |
| **transform** | 形态变化 | 外观、结构 | Transform the data |
| **change** | 通用改变 | 任何改变 | Change the color |
| **alter** | 修改、改动 | 部分改变 | Alter the design |
| **modify** | 调整、修改 | 功能调整 | Modify the code |
| **translate** | 翻译、转换 | 语言、格式 | Translate to Spanish |

> [!tip] 语义等级
> ```
> change（通用）
>   ↓
> alter（部分修改）
>   ↓
> modify（功能性调整）
>   ↓
> transform / convert（根本性改变）
> ```
