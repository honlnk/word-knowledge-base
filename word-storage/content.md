# content

## ⚠️ 重要说明

> [!warning] 这不是前缀词！
> 虽然 content 以 **con-** 开头，但 **con- 在这里不是前缀**。
> - ✅ content = con + tent (拉丁语：held together)
> - ❌ 不是 con- (前缀) + tent
>
> 参见：[[../prefix/com-]] 中的例外列表

---

## 基本信息

### 这是一个**异读词**（Heteronym）

**异读词** = 拼写相同，但发音、含义、词性都不同的词

| 类型           | 发音         | 重音   | 词性     | 核心含义    |
| :----------- | ---------- | :--- | ------ | ------- |
| **content¹** | /ˈkɒntent/ | 第一音节 | 名词     | 内容、所含之物 |
| **content²** | /kənˈtent/ | 第二音节 | 形容词/动词 | 满足的、使满足 |

> [!tip] 快速记忆
> ```
> 名词读前面：CON-tent（内容）
> 形容词读后面：con-TENT（满足）
> ```

## 📖 含义一：content¹（名词）

### 发音与词性
- **发音**: /ˈkɒntent/ (英式) /ˈkɑːntent/ (美式)
- **重音**: 第一音节 **CON**-tent
- **词性**: 名词 (n.)

### 核心含义

#### 1. 内容、所含之物

表示某物内部包含的东西。

> [!example] 常见用法
> ```
> The **content** of the box. (盒子里的内容)
> Check the **content** of the email. (检查邮件内容)
> Water has a high water **content**. (水的含水量很高)
> ```

#### 2. （书的）目录

特指书前面的目录页。

> [!example] 典型搭配
> ```
> the table of **contents** (目录)
> See page 5 in the **contents**. (见目录第5页)
> ```

#### 3. （作品的）内容、素材

指文章、演讲、网站、视频等包含的具体内容。

> [!example] 常见搭配
> ```
> digital **content** (数字内容)
> video **content** (视频内容)
> create **content** (创作内容)
> graphic **content** (画面内容)
> ```

#### 4. 容量、体积、含量

某物所容纳的量。

> [!example] 科学用法
> ```
> fat **content** (脂肪含量)
> alcohol **content** (酒精含量)
> moisture **content** (含水量)
> ```

## 😊 含义二：content²（形容词/动词）

### 发音与词性
- **发音**: /kənˈtent/
- **重音**: 第二音节 con-**TENT**
- **词性**: 形容词 (adj.) / 动词 (v.)

### 形容词含义

#### 满足的、满意的、甘心的

表示对现状感到满足，不需要更多。

> [!example] 常见用法
> ```
> She is **content** with her life. (她对生活感到满足)
> I'm **content** to wait. (我愿意等待/我满足于等待)
> a **content** smile (满意的微笑)
> ```

### 动词含义

#### 使满足、使满意

使某人感到满足。

> [!example] 用法示例
> ```
> Nothing can **content** him. (没有什么能让他满足)
> He **contented** himself with a simple meal. (他满足于一顿简单的饭菜)
> ```

## 🔬 词源分析

### 词源结构

```
拉丁语: continere
    ↓
过去分词: contentus (contained, satisfied)
    ↓
古法语: content
    ↓
英语: content
```

### 构词拆解

```
content = con- (together) + tenere (to hold) + -tus (past participle)
    ↓
   "held together" → "contained" → "full"
```

**关键点**：
- 这里的 **con-** 是拉丁语词根的一部分，**不是前缀**
- **tent** 来自拉丁语 *tenere* (to hold)，不是英语单词 tent (帐篷)
- 整个词来自 *continere* (to hold together, to contain)

### 两个含义的内在联系

虽然看起来含义不同，但实际上有深刻的联系：

```
"充满"的状态 → 不再需要更多 → 满足

content (内容)    → 装满的东西
content (满足)    → 充满的感觉

核心概念：FULLNESS (满)
```

> [!info] 记忆技巧
> 想想中文的"满足"：
> - 满足了 = 充满了
> - 内容 = 装满的东西
>
> 英文的 content 也有同样的逻辑联系！

## ⚠️ 常见误解辨析

### 误解1：content 包含 con- 前缀

**错误认识** ❌
```
content = con- (前缀，"一起") + tent (帐篷)
```

**正确认识** ✅
```
content = con + tenere (拉丁语"hold"的过去分词)
       = continere 的简化形式
       不是前缀 + 单词的结构
```

### 误解2：content² 很少见

**实际情况**：
- content² (满足的) 虽然不如 content¹ (内容) 常见
- 但在日常英语中仍然经常出现
- 常见搭配：be content with, contented

### 误解3：content 和 contented 没区别

| 单词 | 词性 | 使用场景 |
|:-----|------|----------|
| **content** | 形容词（表语） | 作表语：He is content. |
| **contented** | 形容词（定语/表语） | 可作定语：a contented man. |

> [!example] 对比
> ```
> ✓ He is content with his life. (他对生活满意)
> ✓ He is a contented man. (他是一个满足的人)
> ✗ He is a content man. (不太自然)
> ```

## 💡 记忆技巧

### 技巧1：发音位置记忆法

```
名词-重音在前（CON-tent）
→ "内容"是具体的东西，在前面的、可见的

形容词-重音在后（con-TENT）
→ "满足"是内心的感受，在后面的、抽象的
```

### 技巧2：词根串记法

记住一组：tenere (to hold, to keep)
- **contain** (包含) - con + tain
- **content** (内容/满足) - con + tent
- **continue** (继续) - con + tinue
- **retain** (保留) - re + tain
- **maintain** (维持) - main + tain

### 技巧3：场景联想法

```
场景1：打开手机看内容
→ I check the **content** (/ˈkɒntent/) of the app.
→ 看内容（名词）

场景2：朋友问你想要更多吗
→ I'm **content** (/kənˈtent/) with what I have.
→ 我很满足（形容词）
```

## 🎯 同义词对比

### content¹ (内容) 的同义词

| 单词            | 侧重点       | 适用场景        |
| :------------ | --------- | ----------- |
| **content**   | 通用，可指任何内容 | 书、网站、思想等    |
| **contents**  | 具体项目的列表   | 盒子里的东西、书的目录 |
| **substance** | 实质性的内容    | 讲话的意义、实质    |
| **material**  | 材料、素材     | 学习材料、创作素材   |

### content² (满足) 的同义词

| 单词 | 侧重点 | 适用场景 |
|:-----|--------|----------|
| **content** | 满足现状，不想改变 | 日常表达 |
| **satisfied** | 得到想要的，满意 | 更常见，更通用 |
| **happy** | 快乐、高兴 | 更广泛 |
| **pleased** | 高兴、满意 | 礼貌表达 |
| **contented** | 满足的（可作定语） | 描述人的状态 |

## 📝 学习笔记

### 复习要点
- [ ] content 是异读词，有两个发音和含义
- [ ] 名词读 CON-tent（内容），形容词读 con-TENT（满足）
- [ ] **不是** con- 前缀词，来自拉丁语 continere

### 常见错误提醒

- [ ] ❌ 不要混淆 content 和 contented 的用法区别
