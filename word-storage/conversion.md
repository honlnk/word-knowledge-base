# conversion

## 基本信息

- **发音**: /kənˈvɜːʃn/ (英式) /kənˈvɜːrʒn/ (美式)
- **词性**: 名词 (noun)
- **可数性**: 可数和不可数
- **来源**: 动词 convert 的名词形式

---

## 核心含义

### 名词 (n.)

**转变、转换、改变**

表示从一种形式、状态或用途转变为另一种的过程或结果。

> [!tip] 核心概念
> **conversion = 彻底的改变**
> - 从 A 变成 B（完全不同的性质）
> - 不仅仅是表面的变化，而是本质的转变

### 基本含义

1. **转变、转换**
   - 从一种形式变成另一种形式
   - The conversion of water into steam

2. **改变信仰**
   - 宗教或信仰的改变
   - His conversion to Buddhism

3. **换算**
   - 数值单位的转换
   - Metric conversion

4. **（足球）得分转换**
   - 将达阵（try）转化为追加得分
   - A successful conversion

> [!example] 常见用法
> ```
> **currency conversion** (货币兑换)
> **energy conversion** (能量转换)
> **file conversion** (文件转换)
> **conversion rate** (转化率)
> ```

## 🔬 词源分析

### 构词结构

```
conversion = con- + vers + -ion
```

**构词解析**：
conversion 来自拉丁语 **convertere**（完全转变），由以下部分组成：
- `con-` 前缀表示"完全、彻底"（com- 的变体，在 v 前变成 con-）
- `vertere` 词根表示"转动、转变"
- `-sion` 后缀将动词变成名词
- 整体含义是"彻底转动"→"完全转变"

### 构词拆解

```
conversion = con- + vertere + -sion
               ↓
   con- (completely) + vertere (to turn)
               ↓
      "to turn completely" → "to transform"
               ↓
         conversion (完全的转变)
```

### 词源演变路径

```
拉丁语: convertere (to turn completely)
    ↓
过去分词: conversus
    ↓
古法语: conversion
    ↓
英语 (13世纪): conversion (n.)
              convert (v.)
现代义: "转变、转换、改变信仰"
```

### 🔤 词根详解：vert- / vers-

**什么是 vert-/vers-？**

- **来源**：拉丁语 **vertere** (to turn, to rotate)
- **含义**：转动、转变、改变方向
- **频率**：**非常重要的词根！** 在英语中出现频率极高

#### 核心含义：转动 = 转变

```
物理转动 → 抽象转变
  ↓
方向改变 → 观点改变
状态改变 → 形式改变
```

## 🌿 词根家族：vert- / vers-

都来自拉丁语词根 **vertere** (to turn)：

| 单词 | 构词 | 含义 | 记忆提示 |
|:-----|------|------|----------|
| **convert** | con- (完全) + vert | 转换、改变信仰 | 完全转动 |
| **conversion** | con- + vers + -ion | 转变、转换 | 转动的名词 |
| **divert** | di- (away) + vert | 转移、消遣 | 转向别处 |
| **diversion** | di- + vers + -ion | 转移、娱乐 | 转移注意力 |
| **invert** | in- (into) + vert | 使颠倒、反转 | 向里翻转 |
| **inversion** | in- + vers + -ion | 倒置、反转 | 倒转的状态 |
| **revert** | re- (back) + vert | 恢复、回到 | 转回去 |
| **reversal** | re- + vers + -al | 颠倒、反转 | 转回去的动作 |
| **adversary** | ad- (against) + vers + -ary | 对手、敌手 | 转向对立面 |
| **adverse** | ad- + verse | 不利的、相反的 | 转向对立的 |
| **reverse** | re- (back) + verse | 颠倒、相反 | 转向反方向 |
| **versatile** | vers + -atile | 多才多艺的 | 能多方向转动的 |
| **version** | vers + -ion | 版本、译本 | 转变出来的形式 |
| **conversation** | con- + vers + -ation | 对话、交谈 | 一起转变（思想） |
| **introvert** | intro- (向内) + vert | 内向的人 | 转向自己 |
| **extrovert** | extro- (向外) + vert | 外向的人 | 转向外部 |

> [!info] 词根记忆规律
> ```
> 动词多用 vert-：convert, divert, invert, revert
> 名词多用 vers-：conversion, diversion, inversion, version
>
> 注意：conversation 是例外（con- 一起 + vers 转动 + -ation）
> ```

## 📊 convert vs conversion 对比

### 词性与用法对比

| 特征 | convert | conversion |
|:-----|--------|------------|
| **词性** | 动词 (v.) | 名词 (n.) |
| **发音** | /kənˈvɜːt/ (动) | /kənˈvɜːʃn/ |
| **重音** | 第二音节 | 第二音节（-sion 前移） |
| **含义** | 转换、改变 | 转换的过程/结果 |
| **可数性** | - | 可数/不可数 |

### 动词 convert 的用法

```
✓ convert something to/into something (把...转换成...)
✓ convert from A to B (从A转换成B)
✓ convert somebody to something (使某人改变信仰)

例句：
They **converted** the garage into a studio. (他们把车库改成了工作室)
Solar panels **convert** sunlight into electricity. (太阳能板把阳光转化成电)
He **converted** to Islam. (他改信伊斯兰教)
```

### 名词 conversion 的用法

```
✓ undergo conversion (经历转换)
✓ complete conversion (完成转换)
✓ facilitate conversion (促进转换)

例句：
The **conversion** of the building took six months. (建筑改造用了六个月)
Currency **conversion** is available at the bank. (银行提供货币兑换)
The **conversion** rate is increasing. (转化率在增长)
```

## ⚠️ 常见错误与注意点

### 错误1：混淆 change 和 conversion

```
❌ Use conversion for any small change
✓ conversion = 完全、彻底的改变
✓ change = 任何改变（大小皆可）

conversion 暗示性质或本质的改变
change 可以是表面的、微小的改变
```

### 错误2：发音错误

```
❌ /kənˈvɜːt/ (读成 convert)
✓ /kənˈvɜːʃn/ (注意 -sion 发音 /ʃn/)

conversion 的重音位置与 convert 相同（都在第二个音节）
但结尾是 /ʃn/ 不是 /t/
```

### 错误3：动词用法错误

```
❌ conversion something to something
✓ convert something to something (动词)
✓ the conversion of something (名词)

错误：I conversioned the file.
正确：I converted the file. / The file conversion is done.
```

## 💼 同义词辨析

### 表示"改变、转换"的词

| 单词 | 词性 | 侧重点 | 使用场景 | 例句 |
|:-----|------|--------|----------|------|
| **conversion** | 名词 | 彻底转变 | 形式、性质、信仰 | Conversion to digital format |
| **transformation** | 名词 | 形态变化 | 外观、形式 | Dramatic transformation |
| **change** | 名词 | 通用改变 | 任何改变 | A change in plans |
| **alteration** | 名词 | 修改、改动 | 部分改变 | Minor alterations to the design |
| **modification** | 名词 | 调整、修改 | 功能调整 | Software modification |

> [!tip] 语义等级
> ```
> change（通用）
>   ↓
> alteration（部分修改）
>   ↓
> modification（功能性调整）
>   ↓
> transformation / conversion（根本性改变）
> ```
