# admit

## 基本信息

- **发音**: /ədˈmɪt/ (英式 & 美式)
- **词性**: 动词 (verb) - 及物和不及物
- **来源**: 拉丁语 admittere (让进入)

---

## 核心含义

### 动词 (v.)

**承认、准许进入、接纳**

> [!tip] 核心记忆
> **admit = 让通过、让进来**
> - ad- (to) + mit (send) = send to (送到)
> - 让人/事进来 = 准许进入
> - 让想法进来 = 承认

### 基本含义

1. **承认、供认**
   - 承认某事属实或某人有某品质
   - He **admitted** his mistake. (他承认了自己的错误)

2. **准许进入、接纳**
   - 允许某人进入某地或某组织
   - The ticket **admits** one person. (这张票允许一个人进入)

3. **容纳、接纳**
   - 足够大能容纳
   - The room **admits** 50 people. (这个房间能容纳50人)

> [!example] 常见用法
> ```
> **admit something** (承认某事)
> **admit to something** (承认做某事)
> **admit that** (承认...)
> **admit somebody to** (准许某人进入)
> **be admitted to** (被接纳进入)
> ```

## 🔬 词源分析

### 构词结构

```
admit = ad- + mit + t
```

**构词解析**：
admit 来自拉丁语 **admittere**（让进入），由以下部分组成：
- `ad-` 前缀表示"to, toward"（向、朝）
- `mittere` 词根表示"to send, to let go"（送、让过）
- 动词结尾表示现在时
- 整体含义是"let send to"→"allow to through"→"allow to enter"

### 构词拆解

```
admit = ad- + mittere + (动词结尾)
            ↓
   ad- (to) + mittere (to send/let go)
            ↓
      "to let go through to" → "to allow to enter"
            ↓
         admit (承认、准许进入)
```

### 词源演变路径

```
拉丁语: admittere (to let pass through)
    ↓
古法语: admettre
    ↓
英语 (15世纪): admit
现代义: "承认、准许进入"
```

### 🔤 词根详解：mit- / miss-

**什么是 mit-/mississ-？**

- **来源**：拉丁语 **mittere** (to send, to let go)
- **含义**：送、派、让过
- **频率**：**非常重要的词根！** 技术和日常英语中都很常见

#### 核心含义：send = let go

```
送 → 让过
  ↓
让别人通过 → 允许
送过去 → 传输
送上去 → 提交
```

> [!info] 关键规律
> **动词用 mit-，名词用 miss-**
> ```
> admit (动词)   →   admission (名词)
> permit (动词)  →   permission (名词)
> submit (动词)  →   submission (名词)
> transmit (动词) →   transmission (名词)
>
> 为什么？因为 mittere 的过去分词是 missum
> ```

## 🌿 词根家族：mit- / miss-

都来自拉丁语词根 **mittere** (to send, to let go)：

| 单词 | 构词 | 含义 | 记忆提示 |
|:-----|------|------|----------|
| **permit** | per- (through) + mit | 允许、许可 | 让...通过 |
| [[permission]] | per- + miss + -ion | 许可、准许 | 让通过的名词 |
| **admit** | ad- (to) + mit | 承认、准许进入 | 让进入 |
| **admission** | ad- + miss + -ion | 承认、入场费 | 让进入的名词 |
| **submit** | sub- (under) + mit | 提交、屈服 | 送交下面 |
| **submission** | sub- + miss + -ion | 提交、服从 | 送交的名词 |
| **transmit** | trans- (across) + mit | 传输、传播 | 送过去 |
| **transmission** | trans- + miss + -ion | 传输、传播 | 送过去的名词 |
| **emit** | e- (out) + mit | 发出、发射 | (送出) |
| **emission** | e- + miss + -ion | 发射、排放 | (送出的名词) |
| **dismiss** | dis- (away) + miss | 解散、驳回 | 送走 |
| **mission** | miss + -ion | 任务、使命 | 被派出的 |
| **commit** | com- (together) + mit | 委托、承诺 | 一起送 |
| **commission** | com- + miss + -ion | 委员会、委托 | 被委托的任务 |
| **remit** | re- (back) + mit | 汇款、宽恕 | 送回 |
| **remission** | re- + miss + -ion | 缓解、汇款 | 送回的结果 |
| **intermit** | inter- (between) + mit | 暂停、间断 | (中间送) |
| **intermission** | inter- + miss + -ion | 间歇、幕间休息 | 中间的间隔 |
| **omit** | o- (out) + mit | 省略、遗漏 | (送出去) |
| **omission** | o- + miss + -ion | 省略、遗漏 | 被省略的 |

> [!tip] 词根记忆规律
> ```
> 动词多用 mit-：permit, admit, submit, transmit, emit
> 名词多用 miss-：permission, admission, submission, transmission
>
> 例外：mission 本身就是名词 (被派出的东西)
>       dismiss 本身就是动词 (用 miss)
> ```

```
ad- (to, toward) + mit (send) = send to

### 方法2: 场景联想法

```
场景1：守卫问话

→ 承认事实



场景2：入场检票
→ This ticket **admits** one person.

→ He was **admitted** to the hospital.

```

### 方法3: 对比记忆法

```
admit vs confess vs acknowledge

admit      承认（通用，可能是事实）
confess    供认（通常指错误、罪行）
acknowledge 承认（正式，确认事实）

He **admitted** he was the thief.（他承认他是小偷）
He **confessed** to the crime.（他供认了罪行）
He **acknowledged** the receipt.（他确认收到收据）
```

## ⚠️ 常见错误与注意点

### 错误1：混淆 admit 和 acknowledge

```
❌ Use admit for formal confirmation
✓ acknowledge = 正式确认
✓ admit = 承认（可以是被迫的）

He acknowledged the letter.（他确认收到信）
He admitted he received it.（他承认收到了）
```

### 错误2：介词搭配错误

```
❌ admit about something
❌ admit for something
✓ admit to something（承认某事）
✓ admit something（直接接宾语）
```

### 错误3：名词形式错误

```
❌ admition
✓ admission

规律：mit- (动词) → miss- + -ion (名词)
```

|:-----|------|----------|------|

## 🎯 实际应用示例

```markdown
**Admitting Mistakes (承认错误)**

"I **admit** I was wrong about that."
(我承认我对那件事错了。)

(你必须承认，那真的挺搞笑的。)

```markdown
**School Admission (学校入学)**

"The admission fee is $5 for adults."

```

```markdown
**Hospital Admission (医院入院)**

"The patient was **admitted** to ICU."

"He needs immediate **admission**."
(他需要立即入院。)

(入院后，医生给他做了检查。)
```
