# exception

## 基本信息

- **发音**: /ɪkˈsepʃn/ (英式 & 美式)
- **词性**: 名词 (noun)
- **可数性**: 可数和不可数
- **来源**: 动词 [[except]] 的名词形式

---

## 核心含义

### noun - **例外、例外情况、异常**

**核心含义**

> [!tip] 核心记忆
> **exception = 被拿在一边的东西** (ex- + capere) → 例外

### 基本含义

1. **例外、除外**
   - 不包括在一般规则之外的人或事物
   - A person or thing that is excluded from a general statement

2. **异常情况**
   - 不符合规则或常态的事物
   - Something that does not follow a rule

3. **（法律）异议**
   - 法律程序中的反对意见

> [!example] 常见用法
> ```
> Most of the buildings are new, but this church is an **exception**.
> (大多数建筑都是新的，但这座教堂是个例外)
>
> Without **exception**, all students passed.
> (所有学生都通过了，无一例外)
>
> Heavy snow is the **exception** rather than the rule here.
> (在这个地区，大雪是异常情况而非常态)
> ```

## 🔬 词源分析

### 构词结构

```
exception = ex- (前缀) + capere (拉丁词根) + -tion (后缀)
```

**构词解析**：
exception 来自觉丁语 **exceptus**，是 **excipere** 的过去分词：
- `ex-` 前缀表示"out"（向外）
- `capere` 词根表示"to take"（拿、取）
- 整体含义是"taken out"（被拿出来的）

> [!info] 何时添加构词解析？
> - exception 的构词有特殊拼写变化（p → t），需要添加构词解析
> - 帮助理解为什么不是 expection

### 构词拆解

| 组成部分          | 来源    | 含义        | 作用      |
| :------------ | ----- | --------- | ------- |
| **[[ex-]]**   | 拉丁语前缀 | out, 向外   | 表示"拿出去" |
| **[[-cept-]]**    | capere (拉丁词根)  | take, 拿、取 | 核心动词    |
| **[[-ion]]** | 名词后缀  | 动作的结果     | 将动词变成名词 |


### 词源演变路径

```
拉丁语: excipere (to take out)
    ↓
过去分词: exceptus
    ↓
古法语: exception
    ↓
英语: exception (noun)
      except (verb/preposition)
```

> [!info] 词根记忆
> 同样来自 **capere** (to take) 的词：
> - **capture** (捕获)
> - **capacity** (容量)
> - **capable** (有能力的)

## 🔤 后缀详解：-tion

**什么是 -tion？**

- **类型**：名词后缀 (noun suffix)
- **功能**：将动词变成名词
- **来源**：拉丁语 -tionem
- **发音**：/ʃn/

### 动词 → 名词

```
except (动词/介词) → exception (名词)
```

### 为什么是 exception 而不是 expection？

这是一个特殊的拼写变化！

```
excipere (拉丁语动词)
    ↓
exceptus (过去分词，p 变成 t)
    ↓
exception (不是 expection!)
```

> [!tip] 判断技巧
> ```
> 以 -pt 结尾的词 → 直接加 -ion
>
> except → exception ✓
> concept → conception ✓
> percept → perception ✓
>
> 规律：拉丁语过去分词中的 pt 在英语中保持
> ```

## 💡 记忆技巧

### 方法1: 词根逻辑记忆

```
ex- (向外) + capere (拿) = 拿出去
      ↓
  把某个东西从整体中拿出来
      ↓
    那个东西就是"例外"
```

### 方法2: 场景联想法

```
想象分糖果：
- 所有孩子都在排队（规则）
- 只有一个孩子被拿出来站在一边
- 那个孩子就是 exception（例外）
```

### 方法3: 对比记忆法

```
规则 vs 例外
rule (规则) ←→ exception (例外)
norm (常态) ←→ exception (异常)
```

## 📚 常用搭配

### 介词搭配

| 搭配 | 含义 | 例句 |
|:-----|------|------|
| **with the exception of** | 除...之外 | I enjoyed all his novels with the exception of the last one. |
| **without exception** | 无一例外 | All applicants must be over 18, without exception. |
| **make an exception** | 破例 | I'll make an exception for you this time. |
| **take exception to** | 介意、反对 | He took exception to my comments about his work. |
| **be the exception to** | 是...的例外 | He's the exception to the rule. |

| **with no exception** | 毫无例外 | Everyone must attend, with no exception. |

## ⚠️ 常见误解辨析

### 误解1: exception = 异常（贬义）

**错误认识** ❌
```
exception 总是表示"错误、问题"
```

**正确认识** ✅
```
exception = 例外（中性词）
- 可以是好的例外（天才学生）
- 可以是坏的例外（异常情况）
- 只是表示"不符合规则"
```

### 误解2: exception 和 exceptional 没区别

| 单词 | 词性 | 含义 | 使用场景 |
|:-----|------|------|----------|
| **exception** | 名词 | 例外 | 描述不符合规则的事物 |
| **exceptional** | 形容词 | 杰出的、卓越的 | 正面含义，描述优秀的 |

> [!example] 对比
> ```
> ✓ She is the exception to the rule. (她是规则的例外)
> ✓ She is an exceptional student. (她是个卓越的学生)
> ```

### 误解3: exceptionable 和 exceptional 相似

| 单词 | 含义 | 使用频率 |
|:-----|------|----------|
| **exceptional** | 杰出的、卓越的 | 常用 ✓ |
| **exceptionable** | 可反对的、有问题的 | 罕见 ✗ |

> [!warning] 注意
> ```
> exceptional = 杰出的（褒义）
> exceptionable = 可反对的（贬义，几乎不用）
>
> 实际上 exceptionable 在现代英语中极少使用
> ```

## 🎯 同义词辨析

### 表示"例外、异常"的词

| 单词 | 侧重点 | 使用场景 | 例句 |
|:-----|--------|----------|------|
| **exception** | 不符合规则 | 最通用，任何场景 | This is an exception. |
| **anomaly** | 反常的、异常的 | 科学、数据分析 | This data is an anomaly. |
| **deviation** | 偏离标准 | 统计、技术 | Deviation from the norm. |
| **irregularity** | 不规则 | 规则、程序 | Found irregularities in the accounts. |
| **aberration** | 临时偏离 | 医学、心理 | A temporary aberration. |
