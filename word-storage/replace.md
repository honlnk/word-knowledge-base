# replace

## 基本信息

- **发音**: /rɪˈpleɪs/ (英式 & 美式)
- **词性**: 及物动词 (vt.)
- **等级**: B2（常用核心词汇）
- **来源**: 拉丁语 *placere* (to place, to put)

---

## 核心含义

### verb - **替换、代替、取代**

> [!tip] 核心记忆
> **replace = re- (back/again) + place (放置) = 重新放回去**
> 核心概念是"把旧的东西拿走，放新的回去"，强调占据原有位置

---

## 🔬 词源分析

### 构词结构

```
replace = re- + place
           ↓        ↓
      back/again  to put
           ↓
    put back again → 放回去
           ↓
        替换、代替
```

**构词解析**：

replace 来自古法语 **replacer**（put back again），由以下部分组成：
- `re-` 前缀表示"back"（回去）或"again"（再次）
- `-place-` 来自拉丁语 *placere*，表示"to place, to put"（放置）
- 整体含义是"put back again" → "放回去" → "替换"

| 组成部分            | 来源    | 含义         | 作用          |
| :-------------- | ----- | ---------- | ----------- |
| **[[re-]]**     | 拉丁语前缀 | back/again | 表示动作回到原位或重复 |
| **[[-place-]]** | 拉丁词根  | to put     | 核心动词，表示放置动作 |

### 词源演变路径

```
拉丁语: *placere* (to please, to place)
    ↓
拉丁语: *placer* (to place)
    ↓
古法语: replacier (to put back again, to replace)
    ↓
中古英语: replacen
    ↓
现代英语: replace (15世纪)
现代义: "替换、代替、取代"
```

## 🌿 同源词族

都来自拉丁语词根 **placere** (to place)：

| 单词            | 构词                | 含义       | 记忆提示        |
| :------------- | ------------------ | -------- | ------------ |
| **place**      | plac               | 放置、地点    | 基础词          |
| **replace**    | re- (back) + place | 替换、放回    | 放回去          |
| **displace**   | dis- (away) + place | 移位、置换    | 移开位置         |
| **misplace**   | mis- (wrong) + place | 放错地方    | 放错位置         |
| **replaceable**| replace + -able    | 可替换的     | 能够被替换的      |
| **irreplaceable**| ir- (not) + replaceable | 不可替代的 | 不能被替换的      |
| **replacement** | replace + -ment    | 替换品、替换   | 替换的名词       |

> [!info] 词根记忆规律
> ```
> re- (back/again) + place = replace (放回、替换)
> dis- (away) + place = displace (移开、移位)
> mis- (wrong) + place = misplace (放错)
> ```

## 💡 记忆技巧

### 方法1: 词根逻辑记忆

```
re- (back/again 再次/回去) + place (放) = 再次放
      ↓
   把旧的拿走，放新的回去
      ↓
    replace (替换)
```

### 方法2: 场景联想法

```
场景1：手机坏了买新的
→ I need to **replace** my phone.（我需要换手机）
→ 替换旧的

场景2：员工离职新员工接替
→ She **replaced** me as manager.（她接替我成为经理）
→ 代替我的位置

场景3：书看完放回书架
→ He **replaced** the book on the shelf.
→ 放回原处（词源本义）
```

## ⚠️ 常见误解辨析

### 误解: replace = substitute（相同）

**实际区别** ❌→✅

| 单词      | 侧重点           | 使用场景       | 介词        |
| :------- | ------------ | ---------- | --------- |
| **replace** | **"用新换旧"**，强调**新事物占据旧事物的位置** | 永久性替换      | replace A **with** B |
| **substitute** | **"用A代替B"**，强调**替代功能**，不一定比原来的好 | 临时或功能替代    | substitute A **for** B |

> [!example] 对比示例
> ```
> ✓ I need to replace my phone.（我要换手机 - 旧的去，新的来）
> ✓ Can you substitute for me tomorrow?（你能明天替我吗？- 临时替代功能）
>
> ✓ I replaced sugar with honey.（我用蜂蜜替换了糖 - 永久性改变）
> ✓ I substituted honey for sugar.（我用蜂蜜代替了糖 - 强调替代关系）
> ```

## 📝 学习笔记

### 复习要点

- [ ] **词源**：replace = re- (back/again) + place (put) = 放回去 → 替换
- [ ] **核心含义**：替换、代替、取代
- [ ] **关键搭配**：replace A **with** B（用B替换A）
- [ ] **对比记忆**：replace (新换旧) vs substitute (功能替代)
- [ ] **介词注意**：用 **with** 或 **by**，不用 to

### 常见错误提醒

- [ ] ❌ 不要混淆 replace 和 substitute
- [ ] ❌ 不要说 "replace TO"，要用 "replace WITH"
- [ ] ❌ 不要认为 replace 只能指物，人也可以
- [ ] ✅ 记住：replace 是永久性替换，substitute 是功能性替代
- [ ] ✅ 记住：replace A with B，substitute A for B
