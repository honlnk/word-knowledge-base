# contain

## 基本信息

- **发音**: /kənˈteɪn/ (英式 & 美式)
- **词性**: 动词 (v.)
- **等级**: B2（常用核心词汇）

---

## ⚠️ 重要说明

> [!note] 词源说明
> **contain 和 [[content]] 来自同一个拉丁词：continere**
>
> 虽然可以为了记忆方便拆解成 `con + tain`，但严格来说：
> - ✅ contain 直接来自拉丁语 **continere**（握在一起）
> - ✅ 在现代英语中，为了便于理解，可以分析为 con + tain
> - ⚠️ 但这不是典型的"前缀+词根"构词，而是**拉丁词整体演变**
>
> **对比**：[[content]] 从过去分词演变，contain 直接从动词演变

---

## 核心含义

### verb - **包含、容纳**

> [!tip] 核心记忆
> **contain = hold together（装在一起、控制住）**
> 核心概念是"装住"或"控制住"，不让外泄或扩散

### 主要用法

#### 1. 包含、装有

指某物内部装有另一物，强调空间上的"容纳"。

> [!example] 常见用法
> ```
> The box **contains** books.（箱子里装着书。）
> This drink **contains** alcohol.（这饮料含有酒精。）
> The report **contains** important information.（报告包含重要信息。）
> ```

#### 2. 控制、抑制

阻止情感、行为或事物扩散，强调"控制住"。

> [!example] 常见用法
> ```
> She could hardly **contain** her excitement.（她难以抑制兴奋。）
> He couldn't **contain** his anger.（他无法控制怒火。）
> **contain** the spread of the virus.（遏制病毒传播。）
> ```

#### 3. 等于、可被...整除（数学）

指一个大数可以被另一个数整除。

> [!example] 数学用法
> ```
> 9 **contains** 3 three times.（9是3的3倍。）
> ```

## 🔬 词源分析

### 词源结构

```
拉丁语: continere (to hold together)
    ↓
古法语: contenir
    ↓
中古英语: containen
    ↓
现代英语: contain
```

### 构词拆解（记忆用）

```
contain = con + tain
        ← 拉丁语 continere 的简化形式
```

**关键理解**：
- **原始拉丁词**：**continere** = con- (together) + tenere (to hold)
- **演变过程**：
  - `continere` → `contenir` → `contain`
  - 语音变化：tenere → tain（元音弱化和语音简化）
- **记忆时可以这样理解**：
  - `con-` = 一起
  - `tain` = tenere 的变体 = 握、保持
  - 合起来 = "握在一起" → "包含"

### 词源演变路径

```
拉丁语: continere (to hold together 包含、抑制)
    ↓
古法语: contenir
    ↓
中古英语: containen
    ↓
现代英语: contain
```

### 词根记忆系统

都来自拉丁词根 **tenere** (to hold, to keep)：

| 单词           | 拉丁来源          | 演变路径       | 含义     | 记忆关联            |
| :----------- | -------------- | ---------- | ------ | --------------- |
| **contain**  | continere      | 直接演变       | 包含、控制  | "握在一起" → 装在里面     |
| [[content]]  | contentus      | 通过过去分词演变    | 内容/满足  | "装满的东西" → 满足的状态   |
| [[continue]] | continuare     | 衍生动词       | 继续     | "一直保持"          |
| [[maintain]] | manu tenere    | 复合词（手+保持）  | 维持     | "用手保持"          |
| [[retain]]   | retinere       | 加前缀 re-     | 保留     | "往回保持"          |
| [[detain]]   | detinere       | 加前缀 de-     | 扣留     | "拿住不让走"         |
| [[sustain]]  | sustinere      | 加前缀 sub-    | 支撑     | "在下面保持"         |

> [!info] 记忆技巧
> **这组词的核心是 tenere = 保持、握住**
>
> - **contain** & **content**: 都来自 continere，但演变路径不同
>   - contain → 直接演变（动词）
>   - content → 通过过去分词（名词/形容词）
> - 其他词通过加前缀形成新词：
>   - re**tain** = 往回握住 = 保留
>   - main**tain** = 手握住 = 维持
>   - sus**tain** = 下面托住 = 支撑

## 💡 记忆技巧

### 方法1: 从原始拉丁词记忆

```
continere (拉丁语) = con + tenere
                         ↓
                    握在一起
                         ↓
        ┌────────────────┴────────────────┐
        ↓                              ↓
    contain                        content
   （动词演变）                    （过去分词演变）
        ↓                              ↓
    包含、控制                        内容、满足
```

> [!tip] 理解要点
> **contain 和 content 是"兄弟词"**，都来自同一个父亲 **continere**
> - contain = 哥哥（直接继承父亲的动词性质）
> - content = 弟弟（通过过去分词演变而来）

### 方法2: 简化记忆（适合快速学习）

```
con- (一起) + tain (握) = 握在一起
      ↓
   装在里面、包含
      ↓
   不能外泄、控制
```

### 方法2: 场景联想法

```
场景1：打开盒子看里面
→ The box **contains** toys.（盒子里装着玩具）
→ 装着、包含

场景2：听到好消息忍住笑
→ She can't **contain** her joy.（她无法抑制喜悦）
→ 控制、忍住

场景3：防止火灾扩散
**contain** the fire.（控制火势）
→ 遏制、防止扩散
```

### 方法3: 同根词串记法

记住一组词，都来自 **tenere (hold)**：

```
contain    包含   → 握在一起
content    内容   → 装满的东西
continue   继续   → 一直保持
maintain   维持   → 用手保持
retain     保留   → 拿住不放
```

## ⚠️ 常见误解辨析

### 误解1: contain = include（相同）

**实际区别** ❌→✅

| 单词 | 侧重点 | 使用场景 |
|:-----|--------|----------|
| **contain** | **"装在里面"**，强调**物理或逻辑上的包含** | 盒子里装什么、饮料含什么成分 |
| **include** | **"作为整体的一部分"**，强调**整体中的部分** | 列表中的项目、套餐包含的服务 |

> [!example] 对比示例
> ```
> The box **contains** books.（箱子装着书 - 书在里面）
> The price **includes** tax.（价格包含税 - 税是价格的一部分）
>
> ✓ The album contains 10 songs.（专辑里装着10首歌）
> ✓ The album includes 2 hit songs.（专辑中包含2首热门歌 - 强调重点部分）
> ```

### 误解2: contain 只有"包含"一个含义

**实际情况**：
- contain 还有 **"控制、遏制"** 的重要含义
- 在新闻报道中常见：contain the fire（控制火势）、contain the virus（遏制病毒）

### 误解3: container = contain 的名词形式

**辨析**：

| 单词 | 含义 | 使用场景 |
|:-----|------|----------|
| **container** | 容器 | physical container（物理容器） |
| **containment** | 遏制、控制 | abstract concept（抽象概念） |

> [!example] 对比
> ```
> shipping container  → 集装箱（装货的大铁箱）
> nuclear containment → 核遏制（防止核泄漏的措施）
> ```

## 🎯 同义词对比

### 表示"包含"的动词

| 单词 | 侧重点 | 适用场景 |
|:-----|--------|----------|
| **contain** | 装在里面、容纳（最常用） | 盒子里装什么、含有成分 |
| **include** | 作为一部分 | 列表中的项目、整体的一部分 |
| **hold** | 能容纳多少量 | The room holds 50 people.（房间能容纳50人） |
| **enclose** | 围起来、封在里面 | Please enclose a check.（随信附上支票） |

### 表示"控制"的动词

| 单词 | 侧重点 | 适用场景 |
|:-----|--------|----------|
| **contain** | 控制不让扩散 | contain fire/virus/anger |
| **control** | 一般性控制 | control the situation |
| **suppress** | 压制、镇压 | suppress the rebellion |
| **restrain** | 约束、限制 | restrain from doing something |

## 📝 学习笔记

### 复习要点

- [ ] **起源**：来自拉丁语 continere（握在一起）
- [ ] **核心含义**："握在一起" → 包含、控制
- [ ] **对比学习**：contain 和 [[content]] 是"兄弟词"，来自同一源头
- [ ] **词义区分**：contain（装在里面）vs include（作为一部分）
- [ ] **重要含义**：记住"控制、遏制"这个含义
- [ ] **常用搭配**：contain oneself（控制情绪）

### 常见错误提醒

- [ ] ❌ 不要简单地认为 contain = con- (前缀) + tain (词根)
- [ ] ❌ 正确理解：contain 是拉丁词 continere 的整体演变
- [ ] ❌ 不要混淆 contain 和 include
- [ ] ✅ 记住：contain 和 content 都来自 continere，但演变路径不同

### 同根词复习

```
tenere (Latin) = to hold, to keep
      ↓
contain  → 握在一起 → 包含
content  → 装满的 → 内容/满足

```
