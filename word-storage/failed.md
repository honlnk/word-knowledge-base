# failed

## 基本信息

- **发音**: /feɪld/ (英式 & 美式)
- **词性**: 形容词 (adj.) / 过去分词
- **来源**: 动词 fail 的过去分词形式

---

## 核心含义

### 形容词 (adj.)
- **失败的、不成功的**（核心义）
- **已失效的、无法运作的**
- **未能达到预期的**

> [!tip] 核心记忆
> **failed = 未达目标的、已经失效的** (unsuccessful)

---

## 🔬 词源分析

### 构词结构
```
failed = fail (动词) + -ed (过去分词后缀)
```

**构词解析**：
failed 来源于动词 **fail**，其历史演变如下：
- fail 源自古法语 **faillir**（缺少、欠缺）
- 最终来自拉丁语 **fallere**（欺骗、辜负、使失望）
- 原始含义是"辜负期望、未能兑现承诺"
- 后演变为"未能成功"→"失败"

| 组成部分 | 来源 | 含义 | 作用 |
|:--------|------|------|------|
| **fail** | 古法语 faillir | 失败、未能 | 核心动词 |
| **-ed** | 英语后缀 | 过去分词标记 | 表示完成/被动 |

### 词源演变路径
```
拉丁语: fallere (欺骗、辜负)
    ↓
古法语: faillir (缺少、未能)
    ↓
中古英语: failen (失败)
    ↓
现代英语: fail → failed (失败的)
```

> [!info] 词根深层含义
> 拉丁词根 **fallere** 的原始意思是"使人跌倒、欺骗"，后来演变为"辜负期望"，这个"辜负"的核心含义在现代英语中仍然可见：
> - **failed** = 辜负了期望的、未能成功的
> - **failure** = 辜负、失败

## 🌿 同源词族

都来自拉丁词根 **fallere**（欺骗、辜负、使失望）：

| 单词 | 构词 | 含义 | 记忆关联 |
|:-----|------|------|----------|
| **fail** | 直接来自 faillir | 失败 | 原始动词 |
| **failed** | fail + -ed | 失败的（过去分词） | 已失败的 |
| **failure** | fail + -ure | 失败（名词） | 失败的状态 |
| [[fallible]] | fallere + -ible | 易错的、会犯错的 | 可能被欺骗的 |
| [[fallacy]] | fallere + -acy | 谬误、谬论 | 欺骗性的逻辑 |
| [[infallible]] | in- (不) + fallible | 不可能错的、绝对可靠的 | 不会犯错的 |

> [!info] 词根记忆法
> 记住一套：**fallere = "欺骗、辜负"**
> - fail      → 辜负期望 → 失败
> - failed    → 已辜负的 → 失败的
> - failure   → 辜负的状态 → 失败（名词）
> - fallible  → 可被欺骗的 → 易错的
> - fallacy   → 欺骗性推理 → 谬误

## ⚠️ 常见误解辨析

### 误解1: failed = failing

**错误理解** ❌
```
failed 和 failing 可以互换使用
```

**正确理解** ✅
```
failed  = 过去分词，"已经失败的"（完成状态）
failing = 现在分词，"正在失败的"（进行状态）
```

**对比示例**：
```python
# failed - 已完成的失败
✓ The plan failed (过去式)
✓ This is a failed plan (失败的计划)

# failing - 正在进行的失败
✓ The plan is failing (正在失败)
✓ a failing business (正在走下坡路的企业)
```

### 误解2: failed vs failure

**错误理解** ❌
```
failed 和 failure 意思相同，可以随意使用
```

**正确理解** ✅
```
failed  = 形容词，修饰名词（失败的...）
failure = 名词，指失败这一事件或状态
```

**对比示例**：
```python
# failed - 形容词用法
✓ a failed attempt    (一次失败的尝试)
✓ failed systems      (失效的系统)

# failure - 名词用法
✓ The attempt ended in failure. (尝试以失败告终)
✓ This is a failure.  (这是一个失败)
✗ This is a failed.   (错误用法)
```

### 对比表格

| 单词 | 词性 | 含义 | 用法示例 |
|:-----|------|------|----------|
| **fail** | 动词 | 失败 | Don't fail to do it. |
| **failed** | 形容词/过去分词 | 失败的 | a failed attempt |
| **failing** | 现在分词/形容词 | 正在失败的、衰退中的 | a failing business |
| **failure** | 名词 | 失败（事件/状态） | The failure was unexpected. |
