# permission

## 基本信息

- **发音**: /pəˈmɪʃn/ (英式 & 美式)
- **词性**: 名词 (noun)
- **可数性**: 不可数名词 (uncountable)
- **来源**: 动词 permit 的名词形式

---

## 核心含义

### 名词 (n.) - 不可数

**许可、允许、准许**

表示某人有权做某事的许可或批准。

> [!tip] 核心概念
> **permission = 许可做某事的权力**
> - 某人 allow you to do something → 你得到 permission

### 基本含义

1. **许可、允许**
   - 许可做某事的权力或权利
   - Official approval to do something

2. **准许、同意**
   - 给予的许可或同意
   - Consent or authorization

> [!example] 常见用法
> ```
> You need **permission** to enter. (你需要许可才能进入)
> I gave him **permission** to leave. (我允许他离开)
> Ask for **permission** first. (先请求许可)
> without **permission** (未经许可)
> ```

## 🔬 词根词缀分析

### 词源结构

```
拉丁语: permittere (to allow to pass through)
    ↓
过去分词: permissum
    ↓
古法语: permission
    ↓
英语: permission (noun)
      permit (verb)
```

### 构词拆解

```
permission = per- + mit +tere + -sion (noun suffix)
           ↓
   per- (through) + mittere (to send/let go)
           ↓
      "to let go through" → "to allow"
```

### 🔤 后缀详解：-ion / -sion

**什么是 -ion/-sion？**

- **类型**：名词后缀 (noun suffix)
- **功能**：将动词变成名词
- **来源**：拉丁语 -ionem
- **频率**：**英语最高产的后缀之一！**

#### 核心功能：动词 → 名词

```
动词 (动作) + -ion = 名词 (动作的结果/状态)

permit (允许) + -ion → permission (许可)
transmit (传输) + -ion → transmission (传输)
admit (承认) + -ion → admission (承认)
submit (提交) + -ion → submission (提交)
```

#### 为什么是 -sion 而不是 -ion？

这里有重要规律！

| 动词词根                             | 名词后缀         | 示例                                    |
| :------------------------------- | :----------- | ------------------------------------- |
| **-mit-** (现在时)                  | **-mission** | permission, admission, submission     |
| **-mit-** → 变成 **-miss-** (过去分词) | + **-ion**   | transmission, emission                |
| 其他动词                             | **-tion**    | action, creation, decision            |
| 以 -d/-de 结尾                      | **-sion**    | decision (decide), expansion (extend) |

> [!tip] 判断技巧
> ```
> 1. 如果词根是 mit-/miss- → 用 -sion
> 2. 如果动词以 -d/-de 结尾 → 通常用 -sion
> 3. 其他情况 → 通常用 -tion
>
> permission = miss (过去分词) + ion = mission + ion
> ```

#### -ion/-sion 的发音规律

- **重音位置**：重音总是在 -ion/-sion **前面的音节**
- **发音**：/-sion/ 和 /-tion/ 都读作 /ʃn/

| 动词 | 名词 | 发音对比 |
|:-----|------|----------|
| per**MIT** (/pəˈmɪt/) | per**MIS**sion (/pəˈmɪʃn/) | 重音前移 |
| trans**MIT** (/trænzˈmɪt/) | trans**MIS**sion (/trænzˈmɪʃn/) | 重音前移 |
| ad**MIT** (/ədˈmɪt/) | ad**MIS**sion (/ədˈmɪʃn/) | 重音前移 |
| de**CIDE** (/dɪˈsaɪd/) | de**CI**sion (/dɪˈsɪʒn/) | 重音前移 |

> [!info] 普遍规律
> ```
> 动词：重音通常在最后一个音节
> 名词(-ion)：重音移到 -ion 前的音节
>
> 这是一条非常有用的规律！
> ```

### 关键问题：为什么是 permission 而不是 permition？

> [!question] 常见疑问
> 为什么 permit 变成名词是 **permission** 而不是 **permition**？

**答案**：因为拉丁语动词 **mittere** 的过去分词是 **missum**

| 拉丁语形式 | 含义 | 英语派生词 |
|:----------|------|----------|
| **mitto** | 我送 (现在时) | **mit-** (transmit, emit) |
| **misi** | 我送了 (完成时) | - |
| **missum** | 被送 (过去分词) | **miss-** (mission, admission) |
| **mittens** | 正在送 (现在分词) | **mission** (名词) |

```
permittere 的过去分词 = permissus
                    ↓
               名词形式
                    ↓
             permission (不是 permition!)
```

## 🌿 词根家族：mit- / miss-

都来自拉丁语词根 **mittere** (to send, to let go)：

| 单词               | 构词                    | 含义      | 记忆提示   |
| :--------------- | --------------------- | ------- | ------ |
| **permit**       | per- (through) + mit  | 允许、许可   | 让...通过 |
| **permission**   | per- + miss + -ion    | 许可、准许   | 让通过的名词 |
| **admit**        | ad- (to) + mit        | 承认、准许进入 | 让进入    |
| **admission**    | ad- + miss + -ion     | 入场费、承认  | 让进入的名词 |
| **submit**       | sub- (under) + mit    | 提交、屈服   | 送交下面   |
| **submission**   | sub- + miss + -ion    | 提交、服从   | 送交的名词  |
| **transmit**     | trans- (across) + mit | 传输、传播   | 送过去    |
| **transmission** | trans- + miss + -ion  | 传输、传播   | 送过去的名词 |
| **dismiss**      | dis- (away) + miss    | 解散、驳回   | 送走     |
| **mission**      | miss + -ion           | 任务、使命   | 被派出    |
| **emit**         | e- (out) + mit        | 发出、发射   | 送出     |
| **emission**     | e- + miss + -ion      | 发射、排放   | 送出的名词  |
| **commit**       | com- (together) + mit | 委托、承诺   | 一起送    |
| **commission**   | com- + miss + -ion    | 委员会、委托  | 被委托的任务 |
| **remit**        | re- (back) + mit      | 汇款、宽恕   | 送回     |
| **remission**    | re- + miss + -ion     | 缓解、汇款   | 送回的结果  |

> [!info] 词根记忆规律
> ```
> 动词多用 mit-：permit, admit, submit, transmit
> 名词多用 miss-：permission, admission, submission, transmission
>
> 例外：mission 本身就是名词 (被派出的东西)
> ```

## 📊 permit vs permission 对比

### 词性与用法对比

| 特征 | permit | permission |
|:-----|--------|------------|
| **词性** | 动词 (v.) / 名词 (n.) | 名词 (n.) |
| **动词含义** | 允许、许可 | - |
| **名词含义** | 许可证、执照 | 许可、准许 |
| **可数性** | 作名词时可数 | 不可数 |
| **发音** | /pəˈmɪt/ (动) /ˈpɜːmɪt/ (名) | /pəˈmɪʃn/ |

### 动词 permit 的用法

```
✓ permit somebody to do something (允许某人做某事)
✓ permit something (允许某事)
✓ permit doing something (允许做某事)

例句：
They don't **permit** smoking here. (他们不允许在这里吸烟)
Please **permit** me to explain. (请允许我解释)
```

### 名词 permission 的用法

```
✓ give permission (给予许可)
✓ ask for / request permission (请求许可)
✓ without permission (未经许可)
✓ have permission to do something (有许可做某事)

例句：
You need **permission** to enter. (你需要许可才能进入)
He gave me **permission** to leave. (他允许我离开)
```

### 特殊用法：permit 作为名词

当 permit 作为名词时，意思是"许可证、执照"，是**可数名词**：

```
a parking **permit** (停车许可证)
a work **permit** (工作许可证)
a building **permit** (建筑许可证)
```

## 💡 同义词辨析

### 表示"允许、许可"的词

| 单词 | 词性 | 语气 | 使用场景 | 例句 |
|:-----|------|------|----------|------|
| **permission** | 名词 | 正式 | 请求许可 | Ask for permission |
| **allow** | 动词 | 通用 | 允许做某事 | They don't allow smoking |
| **permit** | 动词 | 正式 | 许可、准许 | Smoking is not permitted |
| **let** | 动词 | 非正式 | 让、允许 | Let me go |
| **authorize** | 动词 | 非常正式 | 授权、批准 | Authorized personnel only |
| **approve** | 动词 | 正式 | 批准、同意 | The plan was approved |
| **consent** | 动词/名词 | 正式 | 同意 | She consented to the plan |

> [!tip] 语气等级
> ```
> 非正式：let
>   ↓
> 通用：allow
>   ↓
> 正式：permit, permission
>   ↓
> 非常正式：authorize, approval
> ```

## ⚠️ 常见错误与注意点

### 错误1：permission 当作可数名词

```
❌ a permission / two permissions
✓ permission (不可数)
✓ a permit (可数，指许可证)
```

### 错误2：动词形式错误

```
❌ permission somebody to do
✓ permit somebody to do (动词)
✓ give permission to do (名词)
```

### 错误3：搭配错误

```
❌ permit for doing something
✓ permit doing something
✓ permission to do something
```

                              ↓

### 技巧3：家族串记法

记住一组：**mission 族** (都是被"送"的)
- **mission** - 任务 (被派出的)

- **submission** - 提交 (送上去的)
