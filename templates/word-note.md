# 单词名称

## 基本信息

- **发音**: /rɪˈkwaɪəd/ (英式 & 美式)
- **词性**: 形容词
- **来源**: 动词 require 的过去分词形式

---

## 核心含义

### adjective - **必须的、强制的**

**核心含义**

> [!tip] 核心记忆
> **required = 不能缺少的** (necessity)，不是"规范的"

---

## 🔬 词源分析

### 构词结构

```
word = prefix (前缀) + root (原始词根，拉丁词根) + suffix (后缀)
```

**构词解析**（可选）：
required 来自觉丁语 **requaerere**（反复寻求），由以下部分组成：
- `re-` 前缀表示"反复、加强"
- `quaerere` 词根表示"寻求、询问"
- 整体含义是"反复追求"→"强烈要求"

> [!info] 何时添加构词解析？
> - 简单直接的构词（如 required）可以省略此段落
> - 复杂或特殊的构词（如 desired = de- + sid- 来自 sidus 星星）需要添加此段落
> - 目的是帮助读者快速理解构词逻辑和语义演变

| 组成部分                | 来源    | 含义       | 作用         |
| :------------------ | ----- | -------- | ---------- |
| **[[prefix-name]]** | 拉丁语前缀 | 反复、加强语气  | 表示动作的重复或加强 |
| **[[root-name]]**   | 原始词根  | 寻求、询问、追问 | 核心动词       |

### 词源演变路径

```
拉丁语: requaerere (反复寻求)
    ↓
古法语: requerre
    ↓
英语 (13世纪): require
    ↓
现代义: "强烈要求、需要"
```

## 💡 记忆技巧

### 方法1: 词根逻辑记忆

```
re- (反复) + quaerere (寻求) = 反复追求
      ↓
  一再追问、强烈要求
      ↓
    必须满足
```

### 方法2: 场景联想法

```
老师反复问："作业交了吗？作业交了吗？"
      ↓
   这是 require（强烈要求）
      ↓
   交作业是 required（必须的）
```

## ⚠️ 常见误解辨析

### 误解: required = "规范的、按格式的"

**错误记忆** ❌
```
"required format" → required = 规范的
```

**正确理解** ✅
```
"required format" = 要求的格式（必须用的格式）
      ↓
required 修饰的是"必要性"，不是"规范性"
```
