# -cept- 词根

## 基本信息

- **来源**: 拉丁语动词 **capere** (to take, to seize, to grasp)
- **发音**: /sept/ 或 /kept/
- **类型**: 有界词根 (bound base) - 不能单独使用，必须结合前缀/后缀
- **使用场景**: 过去分词形式，主要用于名词和形容词

> [!tip] 核心功能
> **-cept-** 是拉丁语动词 *capere* 的过去分词词根，意思是"拿、取、抓住"。
>
> 它是英语中最常见和最高产的词根之一！

---

| 拉丁语形式 | 英文含义 | 词根形式 | 英语派生 |
|:----------|----------|----------|----------|
| **capio** | I take | **-cap-** | capture |
| **cepī** | I took | **-cep-** |
| **captum** | taken (过去分词) | **-capt-** | captive |
| **ceptum** | taken (变体) | **-cept-** | concept, except, accept |

> [!info] 词根变体
> ```
> capere 的多种变体：
> - -cap- (capture, capable)
> - -cip- (incipient, participant)
> - -capt- (captive, capture)
> - -cept- (concept, except, accept, percept)
> - -ceiv- (receive, perceive - 通过法语借用)
>
> 最常见的是 -cept- 形式
> ```

## 核心含义

### **To take, seize, grasp** - 拿、取、抓住

### 1️⃣ **Take** - 拿、取

| 单词 | 构词 | 含义 | 记忆提示 |
|:-----|------|------|----------|
| [[accept]] | ac- (to) + -cept- | 接受 | 拿过来 |
| [[acceptance]] | ac- + -cept- + -ance | 接受（名词） | 接受的状态 |
| [[except]] | ex- (out) + -cept- | 除...之外 | 拿出去 |
| [[exception]] | ex- + -cept- + -ion | 例外 | 拿出去的东西 |
| [[intercept]] | inter- (between) + -cept- | 拦截、窃听 | 在中间拿住 |
| [[precept]] | prae- (before) + -cept- | 规诫、准则 | 预先拿取的规则 |

> [!example] 常见用法

## 💡 记忆技巧

### 方法1: 核心词义记忆

```
-cept- = take (拿)

向里拿 → accept (接受)
向外拿 → except (除外)
一起拿 → concept (概念)
穿过拿 → percept (感知)
中间拿 → intercept (拦截)
```

### 方法2: 前缀场景联想法

```
ac- (向) + cept (拿) = 拿过来 → accept (接受)
ex- (外) + cept (拿) = 拿出去 → except (除外)
con- (共) + cept (拿) = 一起拿 → concept (共同的想法)
per- (穿) + cept (拿) = 穿过拿 → percept (感知)
```

### 方法3: 词族串记法

记住一组：**ception 族** (名词后缀 -ion)

| 动词/形容词 | 名词 | 含义 |
|:-----------|------|------|
| except | **exception** | 例外 |
| accept | **acceptance** | 接受 |
| concept | **conception** | 概念 |
| percept | **perception** | 感知 |
| intercept | **interception** | 拦截 |

## 🔍 同源词根变体

### capere 的各种形式

| 词根形式 | 来源 | 示例 |
|:---------|------|------|
| **-cap-** | 现在时 | capture, capable, capacity |
| **-cip-** | 现在时 | incipient, participant, recipe |
| **-capt-** | 过去分词 | captive, captivity |
| **-cept-** | 过去分词 | concept, except, accept |
| **-ceiv-** | 法语形式 | receive, perceive, conceive (通过法语借用) |

> [!info] 关键区别
> ```
> -cept- 是直接从拉丁语借用的
> -ceiv- 是通过法语借用后发生音变的
>
>cept ≠ ceiv (拼写不同，来源相同)
> concept (概念) ← 拉丁语
> conceive (构想) ← 法语
> ```

## 🎯 易混淆词对比

### accept vs except

| 特征 | accept | except |
|:-----|--------|--------|
| **前缀** | ac- (向) | ex- (外) |
| **含义** | 接受 | 除...之外 |
| **词性** | 动词 | 介词/动词 |
| **发音** | /əkˈsept/ | /ɪkˈsept/ 或 /ek-/ |

> [!example] 对比
> ```
> ✓ I **accept** your offer. (我接受你的提议)
> ✓ Everyone came **except** Tom. (除了汤姆，大家都来了)
> ```

### concept vs conception

| 特征 | concept | conception |
|:-----|---------|------------|
| **含义** | 概念（具体） | 概念、构想（抽象） |
| **侧重点** | 概念本身 | 概念的形成过程 |
| **常用搭配** | basic concept | conception of |
