# -place- 词根

## 基本信息

- **来源**: 拉丁语 **placere** (to please, to place) 和 **placere** (to place, to put)
- **发音**: /pleɪs/
- **类型**: 自由词根 (free base) - **既可以单独使用，也可以结合前缀/后缀**
- **特殊性**: **基础词汇词根**，place 本身就是一个完整的英语单词

> [!tip] 核心功能
> **-place-** 是一个**自由词根**，place 本身就是一个独立的单词。
>
> 与 mit- 这种"有界词根"不同，place 可以单独使用，也可以加上前缀形成新词。

## 🔬 词源演变

### 拉丁语来源

| 拉丁语形式 | 含义 | 英语派生 |
|:----------|------|----------|
| **placere** | to please, to be pleasing | - |
| **placere** | to place, to put, to set | **place**, replace, displace, misplace |

> [!info] 核心规律
> ```
> place 的词源含义演变：
> placere (to please) → placere (to place) → place (位置、放置)
>
> 记忆：放东西时让人"pleasing"（满意）→ place (放得好)
> ```

### 词源演变路径

```
拉丁语: *placere* (to please, to place)
    ↓
拉丁语: *placere* (to place, to put, to set)
    ↓
古法语: place, replacier
    ↓
中古英语: place, replacen
    ↓
现代英语: place (位置、放置), replace (替换), displace (移位), misplace (放错)
现代义: "位置、放置、安放"
```

### 1️⃣ **To place, to put** - 放置、安放

表示"把东西放在某处"的动作或结果。

## 💡 记忆技巧

### 方法1: 核心含义记忆

```
-place- = to place, to put (放置)
          ↓
    物理动作 → 抽象含义
          ↓
    放东西 → 决定位置 → 安排

place (放) → 替换 (replace) → 移位 (displace) → 放错 (misplace)
```

### 方法2: 前缀场景联想法

```
re- (back/again) + place = replace (放回去 → 替换)
  → I replaced my phone.（我换了手机）

dis- (away) + place = displace (移开位置 → 移位)
  → Workers were displaced by machines.（工人被机器取代了）

mis- (wrong) + place = misplace (放错地方)
  → I misplaced my keys.（我把钥匙放错地方了）
```

### 方法3: 前缀功能记忆

```
前缀功能对比：
re- → 回去 → replace (替换，用新的放回旧的位置)
dis- → 移开 → displace (移位，从原位置移开)
mis- → 错误 → misplace (放错，放到了错误位置)

共同点：都和"改变位置"有关
不同点：改变的方式不同
```

### 方法4: 复合词记忆法

```
place + 具体名词 = 特定地点

birth + place = birthplace (出生地)
fire + place = fireplace (壁炉)
work + place = workplace (工作场所)
market + place = marketplace (市场)

记忆逻辑：place 表示"地点"，前面的词表示"什么性质的地点"
```

## ⚠️ 常见混淆与注意点

### 混淆1: place vs -place-

**实际区别** ❌→✅

| 形式 | 性质 | 使用场景 | 例词 |
|:-----|------|----------|------|
| **place** | 完整单词 | 可以独立使用 | I need a place to live. |
| **-place-** | 词根 | 用于构词分析 | replace, displace |

> [!tip] 理解要点
> ```
> -place- 是一个**自由词根**（free root）
> - 既可以单独使用（place 这个词）
> - 也可以作为词根参与构词（replace, displace）
> - 这是它与 mit-, miss- 等"有界词根"的最大区别
> ```

### 混淆2: place 的多种含义

**place 的主要含义**：

1. **动词：放置、安放**
   - Please place the book on the table.
   - He placed an order.

2. **名词：位置、地点**
   - This is a nice place.
   - Find a place to park.

3. **名词：座位、席位**
   - I saved you a place.
   - Take your place.

4. **名词：住所、家**
   - Come over to my place.
   - Make yourself at home at my place.

> [!example] 语境区分
> ```
> 动词用法：Please **place** your order.（请下单）
> 地点用法：This is a nice **place**.（这是个好地方）
> 座位用法：I saved you a **place**.（我给你留了个座位）
> 家用法：Come over to my **place**.（来我家吧）
> ```

### 混淆3: replace vs substitute

> [!warning] 重要区别
> ```
> **replace** = 用新换旧（永久性，占据位置）
> **substitute** = 功能替代（临时性，不一定改变位置）
>
> 记忆口诀：
> - Replace 用 WITH（replace A with B）
> - Substitute 用 FOR（substitute A for B）
> ```
