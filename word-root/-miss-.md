# -miss- 词根

## 基本信息

- **来源**: 拉丁语动词 *mittere* 的过去分词 **missus**
- **发音**: /mɪs/
- **类型**: 有界词根 (bound base) - 不能单独使用，必须结合前缀/后缀
- **使用场景**: **动词过去分词形式**，主要用于名词

> [!tip] 核心功能
> **-miss-** 是拉丁语动词 *mittere* 的过去分词词根，主要用于**名词**。
>
> 对应的动词形式通常使用 **-mit-**（现在时词根）。

---

## 🔬 语法来源

| 拉丁语形式       | 英文含义           | 词根形式       | 英语派生                           |
| :---------- | -------------- | ---------- | ------------------------------ |
| **missum**  | sent (过去分词)    | **-miss-** | mission, permission, admission |
| **missus**  | I sent         | **-miss-** | mission, messenger             |
| **mittens** | sending (现在分词) | **-miss-** | mission                        |

> [!info] 核心规律
> ```
> 动词现在时 → -mit- (transmit, emit, admit)
> 动词过去分词 → -miss- (mission, permission, admission)
>
> 简单记忆：
> - 动词多用 -mit-
> - 名词多用 -miss-
> ```

## 💡 记忆技巧

### 方法1: 功能记忆

```
-miss- 的功能：
- 动词过去分词形式
- 表示"被送、发送的结果"的名词

对比例子：
mission (名词 - 任务)
permission (名词 - 许可)
admission (名词 - 承认)
```

### 方法2: 动词名词对比记忆

```
动词(-mit-) → 名词(-miss-)
transmit → transmission (送 → 被送的结果)
emit → emission (发出 → 被送出的东西)
permit → permission (允许 → 被允许)
admit → admission (让进 → 被允许进入)
submit → submission (提交 → 被送交)
```

### 方法3: 场景联想法

```
trans- + -miss- → transmission (传输 - 横跨送的结果)
per- + -miss- → permission (许可 - 被允许通过)
ad- + -miss- → admission (入场费 - 被允许进入)
sub- + -miss- → submission (提交 - 被送交下面)
dis- + -miss- → dismissal (解散 - 被送走)

## ⚠️ 常见混淆与例外

### 1. **message 不是直接来自 -miss- 吗？**

**答案**：间接来自 -miss-

```
mittere (to send)
  ↓
missus (过去分词)
  ↓
Old French: message (消息)
  ↓
English: message

所以 message 最终来自 mittere，
但经过了法语演变
```

### 2. **mission 和 missile 的区别？**

**都有关系！**

```
mittere (to send)
  ↓
missum (sent)
  ↓
missile (导弹、发射物 - 被发送的东西)

mittere (to send)
  ↓
missus (sent)
  ↓
mission (任务 - 被派出的使命)
```

### 词根关系

```
-miss- vs -mit- 的关系：
- -miss-: 动词过去分词，表示结果或状态
- -mit-: 动词现在时，表示动作

功能区别：
- 名词 → -miss- (mission, permission, admission)
- 动词 → -mit- (transmit, emit, permit)
```
