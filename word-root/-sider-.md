# -sider- 词根

## 基本信息

- **来源**: 拉丁语名词 **sidus, sideris** (star, constellation) 的属格形式
- **发音**: /saɪdər/
- **类型**: 有界词根 (bound base) - 不能单独使用，必须结合前缀/后缀
- **使用场景**: **属格形式（genitive）**，构词时最常使用

> [!tip] 核心功能
> **-sider-** 是拉丁语名词 *sidus*（星星）的**属格形式**，是英语中最常用的词根形式。
>
> 原始主格形式是 **-sid-**（sidus），但构词时多用属格 **-sider-**（sideris）。

---

## 🔬 拉丁语词根变化

| 拉丁语形式 | 语法 | 词根形式 | 含义 | 英语派生 |
|:----------|------|----------|------|----------|
| **sidus** | 主格 | **-sid-** | 星星、星座 | - |
| **sideris** | 属格 | **-sider-** | 星星的 | **desire**, **consider**, **sidereal** |

> [!info] 为什么主要用属格？
> 拉丁语名词在构词时通常使用属格形式（sideris），所以英语中多用 **-sider-** 形式。
>
> 这就像英语中 "friend of John" 使用 John 的属格一样。

## 核心含义

### 1️⃣ **Star, constellation** - 星星、星座（直接含义）

| 单词 | 构词 | 含义 | 记忆提示 |
|:-----|------|------|----------|
| **sidereal** | -sider- + -eal | 恒星的、以恒星计算的 | 星星的 |
| **siderite** | -sider- + -ite | 陨铁、铁陨石 | 来自星星的石头 |
| **siderolite** | -sidero- + lith (stone) | 石铁陨星 | 星星+石头 |
| **siderostat** | -sidero- + stat (standing) | 定星仪 | 观测星星的仪器 |

> [!example] 常见用法
> ```
> **Sidereal** time is based on Earth's rotation relative to the stars.
> (恒星时是基于地球相对于恒星的自转计算的)
> ```

### 2️⃣ **Longing, desire** - 渴望、期盼（语义演变）

**这是最重要的语义演变！** 从"仰望星空" → "期盼" → "渴望"。

| 单词 | 构词 | 含义 | 记忆提示 |
|:-----|------|------|----------|
| [[desire]] | de- (加强) + -sider- | 渴望、想要 | 强烈期盼星星 |
| [[desired]] | de- + -sider- + -ed | 被期望的、想要的 | 被渴望的 |
| **desiderate** | de- + -sider- + -ate | 渴望、感到缺少 | 渴望星星出现 |
| **desideratum** | de- + -sider- + -atum | 迫切需要之物 | 被渴望的东西 |
| **desiderium** | de- + -sider- + -ium | 渴望、想念 | 渴望的状态 |

> [!info] 词源故事
> 古人仰望星空，期盼星星出现，这种强烈的期盼感逐渐演变为"渴望、期盼"的含义。
>
> ```
> 仰望星空 → 期盼星星出现 → 强烈渴望
>    ↓           ↓                ↓
> sidus → desiderare → desire/desired
> ```

> [!example] 常见用法
> ```
> She **desired** to see him again. (她渴望再见到他)
> This is the **desired** outcome. (这是期望的结果)
> Clean water is a basic **desideratum**. (清洁水是基本需求)
> ```

### 3️⃣ **Consider, examine** - 考虑、细看（隐喻演变）

从"观察星星"（占星术）→ "仔细观察" → "考虑"。

| 单词 | 构词 | 含义 | 记忆提示 |
|:-----|------|------|----------|
| [[consider]] | con- (together) + -sider- | 考虑、认为 | 仔细观察（星星） |
| [[considerable]] | consider + -able | 相当大的、值得考虑的 | 可以考虑的 |
| **considerate** | consider + -ate | 体贴的、考虑周到的 | 考虑别人的 |
| **consideration** | consider + -ation | 考虑、体贴 | 考虑的名词 |
| **inconsiderate** | in- (not) + considerate | 不体贴的 | 不考虑别人的 |

> [!info] 词源演变
> 古代占星学家通过观察星星来预测未来，"观察星星" = "认真思考"：
> ```
> 观察星星（占星）→ 仔细观察 → 深思熟虑
>    ↓              ↓           ↓
> con- + -sider- → consider → consideration
> ```
>
> - **con-** = together/with (一起)
> - **-sider-** = stars (星星)
> - 字面义 = "和星星一起"（观察星星）

> [!example] 常见用法
> ```
> Please **consider** my proposal. (请考虑我的提议)
> He is a **considerate** person. (他是个体贴的人)
> This is a **considerable** amount. (这是相当大的数量)
> ```

## 💡 记忆技巧

### 方法1: 词源故事记忆

```
古罗马的夜晚：
人们仰望星空，期盼星星出现
      ↓
  这种强烈的期盼
      ↓
   成为"渴望" (desire)
```

### 方法2: 构词拆解记忆

```
desire = de- (加强) + -sider- (星星)
      ↓
  强烈期盼星星出现
      ↓
      渴望

consider = con- (一起) + -sider- (星星)
      ↓
  和星星一起（观察）
      ↓
      仔细考虑
```

### 方法3: 语义演变路径

```
星星（原始义）
  ↓
观察星星 → 仔细思考 → consider
  ↓
期盼星星 → 强烈渴望 → desire
  ↓
天体的、恒星的 → sidereal
```

## ⚠️ 常见误解辨析

### 误解: -sider- 总是和"星星"相关

**错误认识** ❌
```
-sider- = star (星星)
consider = 考虑星星？
desire = 想要星星？
```

**正确认识** ✅
```
-sider- 来自星星，但语义已经演变：

1. 直接含义：sidereal（恒星的）
2. 语义演变1：观察星星 → 思考 → consider
3. 语义演变2：期盼星星 → 渴望 → desire

要通过词源演变来理解，不是字面意思！
```

### 词根关系

```
-sider- vs -sid- 的关系：
- -sid-: 主格形式（sidus），原始形式
- -sider-: 属格形式（sideris），构词基础

功能区别：
- 原始名词 → -sid- (sidus)
- 构词基础 → -sider- (desire, consider, sidereal)

构词几乎都用 -sider-
主格形式主要是拉丁语原词
```

### 与其他"星星"词根对比

| 词根 | 来源 | 含义 | 示例 |
|:-----|------|------|------|
| **-sid- / -sider-** | 拉丁语 sidus | 星星（诗意） | desire, consider |
| **astr-** | 希腊语 astron | 星星（科学） | astronomy, astronaut |
| **stell-** | 拉丁语 stella | 星星（普通） | stellar, constellation |
| **celest-** | 拉丁语 caelum | 天空、天堂 | celestial, celerity |

> [!tip] 快速区分
> - **-sid- / -sider-**: 语义演变为"渴望、考虑"（desire, consider）
> - **astr-**: 科学术语（astronomy, astronaut）
> - **stell-**: 直接表示星星（stellar, interstellar）
> - **celest-**: 天空、天堂（celestial）
