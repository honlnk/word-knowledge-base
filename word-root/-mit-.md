# -mit- 词根

## 基本信息

- **来源**: 拉丁语动词 **mittere** (to send, to let go, to cause to go)
- **发音**: /mɪt/
- **类型**: 有界词根 (bound base) - 不能单独使用，必须结合前缀/后缀
- **使用场景**: **动词现在时形式**，主要用于动词

> [!tip] 核心功能
> **-mit-** 是拉丁语动词 *mittere* 的现在时词根，主要用于**动词**。
>
> 对应的名词形式通常使用 **-miss-**（过去分词词根）。

---

## 🔬 语法来源

| 拉丁语形式 | 英文含义 | 词根形式 | 英语派生 |
|:----------|----------|----------|----------|
| **mitto** | I send | **-mit-** | transmit, emit, admit |
| **mittis** | you send | - | - |
| **mittit** | he/she sends | - | - |

> [!info] 核心规律
> ```
> 动词现在时 → -mit- (transmit, emit, admit, submit, permit)
> 动词过去分词 → -miss- (mission, permission, admission, submission)
>
> 简单记忆：
> - 动词多用 -mit-
> - 名词多用 -miss-
> ```

## 💡 记忆技巧

### 方法1: 功能记忆

```
-mit- 的功能：
- 动词现在时形式
- 表示"发送、放开"的动作

对比例子：
transmit (动词 - 传输)
emit (动词 - 发射)
permit (动词 - 允许)
```

### 方法2: 前缀场景联想法

```
trans- = 跨越 → transmit (传输 - 送过去)
e- = 向外 → emit (发射 - 送出)
per- = 穿过 → permit (允许 - 让通过)
sub- = 下面 → submit (提交 - 送下去)
```

### 方法3: 动词名词对比记忆

```
动词(-mit-) → 名词(-miss-)
transmit → transmission
emit → emission
permit → permission
admit → admission
submit → submission
```

### 词根关系

```
-mit- vs -miss- 的关系：
- -mit-: 动词现在时，表示动作
- -miss-: 动词过去分词，表示结果或状态

功能区别：
- 动词 → -mit- (transmit, emit, permit)
- 名词 → -miss- (transmission, emission, permission)
```
