# com- 前缀

## 基本信息

- **来源**: 拉丁语 **cum/com** (with, together)
- **引入途径**: 拉丁语 → 法语 → 英语
- **发音**: /kəm/, /kɒn/, /kɒl/, /kɔːr/, /kəʊ/
- **词性**: 前缀 (prefix)
- **特殊之处**: 有5种拼写变体，取决于后面字母

> [!tip] 核心概念
> 所有变体都表示 **"一起、共同、与...一起"** 的意思

---

## 📝 拼写变体规则

### 为什么有这么多形式？

这是一个**同化现象**（Assimilation）：
- 为了发音方便，前缀会适应后面的字母
- 就像英语不定冠词 a/an，在元音前用 an

### 变体选择表

| 变体 | 使用条件 | 发音辅助记忆 | 口诀 |
|:-----|:---------|:-------------|------|
| [[co-]] | 元音之前 | co-operate | **元音用 co-** |
| [[com-]] | b, m, p 之前 | com-bine, com-pile | **双唇音用 com-** |
| [[con-]] | c, d, g, j, n, q, s, t, v | con-nect, con-tact | **其他辅音用 con-** |
| [[col-]] | l 之前 | col-laborate, col-lect | **l 前用 col-** |
| [[cor-]] | r 之前 | cor-rect, cor-rupt | **r 前用 cor-** |

> [!example] 快速判断
> ```
> co__operate  (元音 o) → co-operate
> com__bine    (辅音 b) → com-bine
> con__nect    (辅音 n) → con-nect
> col__lect    (辅音 l) → col-lect
> cor__rect    (辅音 r) → cor-rect
> ```

### 2️⃣ **Wholly, completely** - 全、完全、加强语气

有时表示"完全"、"彻底"，起加强语气的作用。

| 单词 | 字面义 | 实际含义 | 说明 |
|:-----|--------|----------|------|
| [[complete]] | com- + plete (fill) | 完成、完整的 | 完全填满 |
| [[compress]] | com- + press (press) | 压缩 | 完全压紧 |
| [[confirm]] | con- + firm (strong) | 确认、证实 | 使完全坚定 |
| [[consume]] | con- + sume (take) | 消耗、消费 | 完全拿走 |
| [[continue]] | con- + tinue (hold) | 继续 | 一直持有 |

> [!info] 含义演变
> 从"一起"引申出"完全"：
> - 大家一起做 = 彻底地做
> - 全部聚集在一起 = 完全的

### 选择流程图

```
遇到单词需要判断前缀？

1. 首字母是元音？
   ✓ 是 → co- (cooperate)
   ✗ 否 → 继续

2. 首字母是 b, m, p？
   ✓ 是 → com- (combine)
   ✗ 否 → 继续

3. 首字母是 l？
   ✓ 是 → col- (collect)
   ✗ 否 → 继续

4. 首字母是 r？
   ✓ 是 → cor- (correct)
   ✗ 否 → con- (connect)
```

## ⚠️ 常见混淆与例外

### 1. **不是所有 con- 都是前缀**

有些单词以 con- 开头，但 con- 不是前缀：

| 单词 | 说明 |
|:-----|------|
| [[content]] | 内容、满足 (con- 不是前缀) |
| [[condition]] | 条件 (con- 不是前缀) |
| [[concert]] | 音乐会 (con- 不是前缀) |
| [[conduct]] | 行为、指挥 (con- 不是前缀) |

> [!warning] 辨别方法
> 如果去掉 con- 后剩下的部分不是已知词根，con- 可能不是前缀。
> - connect → nect (词根：连接) ✓ 是前缀
> - content → tent (拉丁语：持有) ✗ 不是前缀

### 2. **易混淆单词对比**

| 单词 | 构词 | 含义 | 区分点 |

## 💡 记忆技巧

### 技巧1：口诀记忆法

```
前缀 com/con 同一家，
"一起、共同" 是它娃。

元音前面 co 安家，
bmp 亲密用 com 抓。
l 字兄弟 col 最搭，
r 字朋友 cor 是它。
其他辅音 con 来查！
```

### 技巧2：发音联想

```
com-  → "Come" (来) → 一起来
con-  → "Connect" (连接) → 连在一起
col-  → "Colleague" (同事) → 一起工作
cor-  → "Correct" (纠正) → 一起改正
co-   → "Cooperation" (合作) → 一起做
```

### 技巧3：词根串记法

记住一组：labor (工作) + 前缀变体
- **elaborate** (e- 向外) → 精心制作（向外扩展工作）
- **collaborate** (col- 一起) → 合作（一起工作）

记住一组：lect (选择/收集) + 前缀变体
- **select** (se- 分开) → 选择（分开挑）
- **collect** (col- 一起) → 收集（一起收）
- **neglect** (neg- 否定) → 忽略（不选）

## 📝 学习笔记

### 复习要点
- [ ] com-/con-/col-/cor-/co- 都来自拉丁语 cum
- [ ] 能够根据后面字母选择正确的变体
- [ ] 理解核心含义：一起、共同、完全
- [ ] 能够区分常见易混淆词

### 常见错误提醒
- [ ] 不要死记硬背，要理解发音同化规律
- [ ] 注意区分前缀词和非前缀词（如 content）
- [ ] 记住口诀：元音co，双唇com，l前col，r前cor，其余con
