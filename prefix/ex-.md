# ex- 前缀

## 基本信息

- **来源**: 拉丁语 **ex** (介词)
- **引入途径**: 拉丁语 → 法语 → 英语
- **发音**: /eks/ 或 /ɪks/ 或 /ɪz/
- **词性**: 前缀 (prefix)

---

## 核心含义

### 1️⃣ **Out, from** - 向外、出去、来自

**最常见含义**，表示"从...向外"或"从...出来"。

| 单词 | 字面义 | 实际含义 | 记忆提示 |
|:-----|--------|----------|----------|
| [[exit]] | ex- + ire (go) | 出口、退出 | 走出去 |
| [[exclude]] | ex- + claudere (shut) | 排除、排斥 | 关在门外 |
| [[exclude]] → [[exclusion]] | | 排除、除外 | 排除的名词 |
| [[expel]] | ex- + pellere (drive) | 驱逐、赶出 | 向外赶 |
| [[extract]] | ex- + trahere (draw) | 提取、拔出 | 拉出来 |
| [[exclude]] | ex- + claudere | 排除 | 关在外面 |
| [[excise]] | ex- + caedere (cut) | 切除、删除 | 切出去 |
| [[expel]] | ex- + pellere | 驱逐 | 向外推 |
| [[extend]] | ex- + tendere (stretch) | 延伸、伸展 | 伸出去 |
| [[expand]] | ex- + pandere (spread) | 扩张、展开 | 展开向外 |

> [!example] 常见用法
> ```
> Please use the emergency **exit**. (请使用紧急出口)
> He was **expelled** from school. (他被学校开除了)
> The dentist **extracted** my tooth. (牙医拔掉了我的牙)
> ```

### 2️⃣ **From, away from** - 离开、脱离

表示"离开"或"脱离"某种状态。

| 单词 | 字面义 | 实际含义 | 记忆提示 |
|:-----|--------|----------|----------|
| [[escape]] | ex- + cappa (cloak) | 逃脱、逃亡 | 脱掉斗篷逃跑 |
| [[evade]] | ex- + vadere (go) | 逃避、躲避 | 走开避开 |
| [[avoid]] | ex- + via (way) | 避免、避开 | 离开道路 |
| [[except]] | ex- + capere (take) | 除...之外 | 拿出去 → 除外 |

> [!example] 常见用法
> ```
> The prisoner **escaped** from jail. (囚犯越狱了)
> You should **avoid** smoking. (你应该避免吸烟)
> Everyone came **except** Tom. (除了汤姆，大家都来了)
> ```

### 3️⃣ **Former, previous** - 前、以前的

表示"以前的"或"前任的"。

| 单词 | 字面义 | 实际含义 | 记忆提示 |
|:-----|--------|----------|----------|
| [[ex-boyfriend]] | ex- + boyfriend | 前男友 | 以前的男朋友 |
| [[ex-president]] | ex- + president | 前总统 | 以前的总统 |
| [[ex-wife]] | ex- + wife | 前妻 | 以前的妻子 |
| [[ex-husband]] | ex- + husband | 前夫 | 以前的丈夫 |

> [!example] 常见用法
> ```
> She is meeting her **ex-boyfriend** tomorrow. (她明天要见前男友)
> The **ex-president** gave a speech. (前总统发表了演讲)
> ```

### 4️⃣ **Completely, thoroughly** - 完全、彻底

少数情况下表示"完全地"或"彻底地"。

| 单词 | 字面义 | 实际含义 |
|:-----|--------|----------|
| [[exhaust]] | ex- + haurire (draw) | 耗尽、使精疲力竭 |
| [[extinguish]] | ex- + tingere (quench) | 熄灭、消灭 |
| [[excoriate]] | ex- + corium (skin) | 严厉批评、剥皮 |

## 🔤 拼写变体

### 变体规则

ex- 在不同辅音前会改变拼写：

| 变体 | 使用条件 | 示例 |
|:-----|----------|------|
| **ex-** | 一般情况 | exit, exclude |
| **ec-** | 在 c 前 | [[ecstasy]] (狂喜) |
| **ef-** | 在 f 前 | [[effect]] (效果), [[effort]] (努力) |
| **es-** | 在 s 前 | [[escape]] (逃脱) |
| **e-** | 在某些词中 | [[evade]] (逃避), [[emit]] (发出) |

> [!tip] 记忆规律
> ```
> ex- 在辅音前的同化：
> c + x → ec-  (ecstasy)
> f + x → ef-  (effect, effort)
> s + x → es-  (escape, esteem)
> 有时简化为 e- (evade, emit)
> ```

## 📊 含义对比与区分

### "Out" vs "From" vs "Former"

| 特征 | Out (向外) | From (来自) | Former (以前的) |
|:-----|-----------|------------|----------------|
| **核心概念** | 从内向外 | 离开某地 | 过去的 |
| **空间感** | 有方向性 | 脱离关系 | 时间指向 |
| **典型例子** | exit (出口) | escape (逃脱) | ex-boyfriend (前男友) |

### 判断技巧

```
Question: 能否替换为 "out of"?
✓ 可以 → "Out" 含义 (exit, exclude)
✗ 不可以 → 可能是其他含义

Question: 能否替换为 "from"?
✓ 可以 → "From" 含义 (escape, except)

Question: 是否指"以前的"?
✓ 是 → "Former" 含义 (ex-president)
```

## 💡 记忆技巧

### 技巧1：核心词义记忆

```
ex- = out (向外)

向外走 → exit (出口)
向外推 → expel (驱逐)
向外拉 → extract (提取)
关在外 → exclude (排除)
```

### 技巧2：场景联想法

```
场景1：走出房间
→ exit (出口) - Out 含义

场景2：离开危险
→ escape (逃脱) - From 含义

场景3：前任伴侣
→ ex-boyfriend (前男友) - Former 含义
```

### 技巧3：词根串记法

记住一组：**pel- 族** (drive, push)
- **expel** (ex- + pel) - 驱逐（向外推）
- **propel** (pro- + pel) - 推进（向前推）
- **compel** (com- + pel) - 强迫（一起推）
- **repel** (re- + pel) - 击退（往回推）

记住一组：**cept- 族** (take)
- **except** (ex- + cept) - 除...之外（拿出去）
- **accept** (ac- + cept) - 接受（拿过来）
- **concept** (con- + cept) - 概念（一起拿到的想法）
- **percept** (per- + cept) - 感知（透过感官拿到的）

## ⚠️ 常见混淆与例外

### 1. **不是所有 ex- 都是前缀**

有些单词以 ex- 开头，但 ex- 不是前缀：

| 单词 | 说明 |
|:-----|------|
| [[example]] | 例子 (ex- 不是前缀) |
| [[exercise]] | 练习、运动 (ex- 不是前缀) |
| [[exam]] | 考试 (ex- 不是前缀) |
| [[exit]] | 出口 (这里 ex- 是前缀 ✓) |

> [!warning] 辨别方法
> 如果去掉 ex- 后剩下的部分是已知词根，ex- 通常是前缀。
> - exit → it (ire, go) ✓ 是前缀
> - exam → -am 不是词根 ✗ 不是前缀

### 2. **extra- vs ex-**

| 前缀 | 含义 | 示例 |
|:-----|------|------|
| **ex-** | 向外、从...出来 | exit, exclude, extract |
| **extra-** | 在...之外、超越 | extraordinary, extrasensory |

> [!tip] 区分技巧
> ```
> ex- = out (从里面出去)
> extra- = beyond (在...之外、超出)
>
> exit (出去) ✓ ex-
> extraordinary (超乎寻常) ✓ extra-
> ```

## 🎯 与其他前缀的对比

| 前缀 | 来源 | 含义 | 方向 | 示例 |
|:-----|------|------|------|------|
| **ex-** | 拉丁语 | 向外、从...出去 | ← 向外 | exit, exclude, extract |
| [[in-]] / [[en-]] | 拉丁语 | 向内、进入 | → 向内 | enter, include, inject |
| [[out-]] | 英语 | 向外、超过 | ← 向外 | output, outcome |
| [[e-]] | 希腊语 | 向外 | ← 向外 | eject, emit |

> [!info] 反义关系
> ```
> ex- (向外) ←→ in-/en- (向内)
>
> exit (出口) ←→ entrance (入口)
> exclude (排除) ←→ include (包括)
> export (出口) ←→ import (进口)
> ```
