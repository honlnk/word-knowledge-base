# dis- 前缀

## 基本信息

- **来源**: 拉丁语 **dis** (apart, away, in different directions)
- **引入途径**: 拉丁语 → 法语 → 英语
- **发音**: /dɪs/, /daɪ/, /dɪf/
- **词性**: 前缀 (prefix)
- **特殊之处**: 有3种拼写变体，取决于后面字母

> [!tip] 核心概念
> 所有变体都表示 **"分开、分离、不、相反"** 的意思

---

## 📝 拼写变体规则

### 为什么有这么多形式？

这是一个**同化现象**（Assimilation）：
- 为了发音方便，前缀会适应后面的字母
- 类似于 [[com-]]/[[con-]]/[[col-]]/[[cor-]] 的变化

### 变体选择表

| 变体 | 使用条件 | 发音辅助记忆 | 口诀 |
|:-----|:---------|:-------------|------|
| [[dis-]] | 大部分辅音前 | dis-approve, dis-connect | **大部分用 dis-** |
| [[dif-]] | f 之前 | dif-fer, dif-fuse | **f 前用 dif-** |
| [[di-]] | l, m, r, v, 元音前 | di-rect, di-vide | **l/m/r/v/元音用 di-** |

> [!example] 快速判断
> ```
> dis__agree   (辅音 g) → dis-agree
> dif__fer     (辅音 f) → dif-fer
> di__rect     (辅音 r) → di-rect
> di__vide     (辅音 v) → di-vide
> di__gest     (辅音 g 在某些词中) → di-gest
> ```

> [!info] 语音同化原理
> 当 **dis-** 遇到某些辅音时，会发生同化：
> - **dis- + f** → **dif-** (fricative 同化) → differ
> - **dis- + l/m/r/v** → **di-** (简化) → direct, divide
>
> 这是为了让发音更流畅！

## 核心含义

### 1️⃣ **Apart, away** - 分开、分离

**最常见含义**，表示把东西分开或分离。

| 单词 | 构词分析 | 实际含义 | 记忆提示 |
|:-----|:---------|----------|----------|
| [[dismiss]] | dis + miss (send) | 解散、遣散 | 送走 |
| [[disconnect]] | dis + connect | 断开连接 | 分开连接 |
| [[dissolve]] | dis + solve | 溶解、解散 | 分开解决 |
| [[distract]] | dis + tract (pull) | 分心、转移 | 拉开 |
| [[distribute]] | dis + tribute (give) | 分配、分发 | 分开给 |
| [[distort]] | dis + tort (twist) | 扭曲、歪曲 | 扭开 |
| [[distinguish]] | dis + tinct (prick) | 区分、辨别 | 分开刺 |
| [[dissect]] | dis + sect (cut) | 解剖、仔细分析 | 切开 |

> [!example] 常见用法
> ```

> ```

## 🔬 dis- vs de- 的关系

### 来源对比

| 前缀 | 拉丁语来源 | 核心含义 | 主要用法 |
|:-----|-----------|----------|----------|
| [[de-]] | de (preposition) | 向下、离开 | descend, depart, decrease |
| **dis-** | dis (adverb/prefix) | 分开、分离 | dismiss, disconnect, divide |

### 含义重叠

虽然来源不同，但**de-** 和 **dis-** 都有"离开、分离"的含义：

| 单词 | 前缀 | 含义 | 偏重 |
|:-----|------|------|------|
| **depart** | de- | 离开、出发 | 强调"走开" |
| **dismiss** | dis- | 遣散、解散 | 强调"分开" |

> [!tip] 快速记忆
> ```
> de- (down/away): 向下走、离开
> dis- (apart): 分开、分离
>
> depart: 从某处离开（强调位置）
> dismiss: 把人分开送走（强调分离）
> ```

## 💡 记忆技巧

### 方法1: 变体规则记忆

```
dis-/di-/dif- 的变化：
├─ dis- (大部分) → dis-connect, dis-agree
├─ dif- (f 前)   → dif-fer, dif-fuse
└─ di- (特殊字母) → di-vide, di-rect, di-gest

记忆口诀：
大部分用 dis，
f 前变成 dif，
l/m/r/v 用 di。
```

### 方法2: 含义分类记忆

```
dis-/di-/dif- 的核心含义：
├─ 1. 分开、分离
│   ├─ dismiss (遣散)
│   ├─ divide (分割)
│   └─ differ (不同)
├─ 2. 不、否定
│   ├─ disagree (不同意)
│   ├─ dislike (不喜欢)
│   └─ disappear (消失)
└─ 3. 相反、撤销
    ├─ discover (发现 - 撤销覆盖)
    ├─ discharge (卸货 - 撤销装载)
    └─ disclose (揭露 - 撤销关闭)
```

### 方法3: 对比记忆

```
dis- vs de-:
├─ dis- (apart): 分开强调"散开"
│   └─ disconnect (断开连接)
└─ de- (down): 离开强调"向下"
    └─ depart (离开出发)
```

## ⚠️ 常见误解辨析

### 误解: dis- 总是表示"不"

**错误认识** ❌
```
dis- = not (不)
→ disconnect = 不连接？
→ divide = 不？？
```

**正确认识** ✅
```
dis- 有多个含义：
1. apart (分开) - dismiss, divide
2. not (不) - disagree, dislike
3. reverse (相反) - discover, discharge

要具体单词具体分析！
```

## 📝 学习笔记

### 复习要点
- [ ] dis-/[[di-]]/[[dif-]] 是**同一个前缀**的语音变体
- [ ] **dis-** (大部分)，**dif-** (f 前)，**di-** (l/m/r/v 前)
- [ ] 核心含义：分开、不、相反
- [ ] 区别于 [[de-]] (向下、离开)

### 常见错误提醒
- [ ] ❌ 不要认为 [[di-]] 是独立前缀
- [ ] ❌ 不要认为 dis- 总是表示"不"
- [ ] ✅ 记住：dis-/[[di-]]/[[dif-]] 是语音变体
- [ ] ✅ 理解：分开、不、相反，三种含义

### 实用记忆口诀

```
dis- 前缀三兄弟：
dis 大部分用，
dif f 前坐，
di 特殊字母（l/m/r/v）。
含义记住三个：
分开、不、相反。
```
