# de- 前缀

## 基本信息

- **来源**: 拉丁语 de- (表示"向下"、"离开"、"加强")
- **引入途径**: 古法语 → 英语 (约1200年)
- **发音**: /diː/ 或 /dɪ/ (取决于后面单词)
- **词性**: 前缀 (prefix)

> [!tip] 核心功能
> **de-** 是一个多义前缀，主要有以下含义：
> 1. **向下** (down) - 表示方向或程度
> 2. **离开、分离** (away/from) - 表示分离
> 3. **加强语气** (intensive) - 强调动作
> 4. **除去、取消** (removal) - 表示去除
> 5. **相反、倒转** (reverse) - 表示反向动作

### 3️⃣ **Intensive** - 加强语气

这是 **de- 最不明显的含义**，表示"加强"、"完全"或"强调"。**desired** 就属于这一类！

| 单词 | 字面义 | 实际含义 | 记忆提示 |
|:-----|--------|----------|----------|
| [[desired]] | de- (intensive) + sider (star) | 被期望的 | 强烈期盼星星 |
| [[desire]] | de- (intensive) + sider | 渴望、想要 | 强烈想要 |
| [[despise]] | de- (intensive) + spic (look) | 鄙视、看不起 | 强烈地看不起 |
| [[demonstrate]] | de- (intensive) + monstr (show) | 证明、演示 | 完全展示 |
| [[declare]] | de- (intensive) + clar (clear) | 宣布、声明 | 完全说清楚 |
| [[definite]] | de- (intensive) + finit (limit) | 明确的、确定的 | 完全限定 |

> [!warning] 重要提醒
> **desired** 的 de- 不是"向下"或"离开"，而是"加强语气"！
> - **desiderare** = **强烈**期盼星星出现
> - 这就是为什么 **desired** 表示"被期望的"而非"向下的"

> [!example] 常见用法
> ```
> She **desired** to see him again. (她渴望再见到他)
> I **demonstrate** the solution. (我演示解决方案)
> He **declared** his innocence. (他宣布自己无罪)
> ```

## ⚠️ 常见误解辨析

### 误解: de- 总是表示"向下"

**错误认识** ❌
```
de- = down (向下)
→ desired = 向下的？
```

**正确认识** ✅
```
de- 有多个含义：
1. down (向下) - decrease, descend
2. away (离开) - depart, detach
3. intensive (加强) ← desired 属于这类！
4. removal (除去) - decode, decompress
5. reverse (相反) - deform, deactivate

要具体单词具体分析！
```
