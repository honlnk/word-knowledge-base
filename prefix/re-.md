# re- 前缀

## 基本信息

- **来源**: 拉丁语 re- (也写作 red-)
- **引入途径**: 古法语 → 英语 (约1200年)
- **发音**: /riː/ 或 /rɪ/ (取决于后面单词)
- **词性**: 前缀 (prefix)

---

## 核心含义

### 1️⃣ **Again, repeatedly** - 再、重新、反复

**最常见含义**，表示动作的重复或再次进行。

| 单词             | 字面义            | 实际含义        | 记忆提示 |
| :------------- | -------------- | ----------- | ---- |
| [[redo]]       | do again       | 重做、重做一遍     | 重新做  |
| [[rewrite]]    | write again    | 重写、重写       | 重新写  |
| [[replay]]     | play again     | 重播、重新播放     | 重新播放 |
| [[rebuild]]    | build again    | 重建、重新建造     | 重新建造 |
| [[reconsider]] | consider again | 重新考虑        | 反复考虑 |
| [[review]]     | view again     | 复习、复查、评论    | 再看一遍 |
| [[renew]]      | make new again | 更新、续期、使...新 | 使之重新 |
| [[reuse]]      | use again      | 重复使用、再利用    | 再次使用 |
| [[refill]]     | fill again     | 再填充、续杯      | 再次装满 |
| [[rearrange]]  | arrange again  | 重新排列        | 重新安排 |
| [[reproduce]]  | produce again  | 繁殖、复制、再现    | 再次生产 |
| [[restart]]    | start again    | 重新开始        | 再次启动 |

> [!example] 常见用法
> ```
> Let me **rethink** this. (让我重新考虑一下)
> Please **resubmit** your application. (请重新提交你的申请)
> I need to **recharge** my phone. (我需要给手机充电)
> ```

### 2️⃣ **Back, backward** - 回、向后、返回

表示向后、返回、回到原状态。

| [[revert]] | turn back | 回复、复原、回归 | 回到原状态 |
| [[reject]] | throw back | 拒绝、驳回 | 扔回去 |
| [[recover]] | get back | 恢复、找回 | 拿回来 |
| [[reappear]] | appear back | 再次出现 | 重新出现 |
| [[recall]] | call back | 回忆、召回、召回 | 叫回来 |
| [[regress]] | go back | 倒退、退化 | 往回走 |
| [[recoil]] | pull back | 反弹、畏缩 | 向后缩 |

> [!example] 常见用法
> ```
> Please **return** the book. (请归还这本书)
> He **recovered** from illness. (他从疾病中恢复了)

> ```

## 📊 含义对比与区分

### "Again" vs "Back" 的区分

| 特征 | Again (再) | Back (回) |
|:-----|:-----------|:----------|
| **核心概念** | 重复动作 | 返回原处 |
| **时间指向** | 未来（再做一次） | 过去（回到之前） |
| **状态变化** | 可能产生新结果 | 回到原状态 |
| **典型例子** | redo (重做) | return (返回) |

### 判断技巧
```
Question: 能否替换为 "again"?
✓ 可以 → "Again" 含义
✗ 不可以 → 可能是 "Back" 含义

例：
replay = play again (Again) ✓
return = come back (Back) ✓
```

## ⚠️ 特殊用法与例外

### 1. **不是所有 re- 都是前缀**

有些单词以 re- 开头，但 re- 不是前缀，而是单词的一部分：

| 单词 | 说明 |
|:-----|------|
| [[read]] | 读取 (re- 不是前缀) |
| [[real]] | 真实的 |
| [[rest]] | 休息、其余 |
| [[red]] | 红色 |
| [[region]] | 区域 |
| [[receive]] | 接收 (re- 不是前缀) |
| [[respect]] | 尊敬 (re- 不是前缀) |

> [!warning] 辨别方法
> 如果去掉 re- 后剩下的部分在英语中有独立含义，则 re- 通常是前缀。
> - read → -ad 不是单词 → re- 不是前缀
> - do → do 是单词 → re- 是前缀

### 2. **连字符规则**

| 情况 | 示例 | 说明 |
|:-----|------|------|
| 不加连字符 | redo, rebuild | 常见组合，无歧义 |
| 加连字符 | re-cover, re-send | 避免歧义或重复字母 |
| 特殊情况 | re-enter (或 reenter) | 两种写法都可 |

```
re-cover (重新覆盖) ≠ recover (恢复)
re-sign (重新签字) ≠ resign (辞职)
```
