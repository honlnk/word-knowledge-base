# -tion 后缀

> [!note] 变体后缀
`-tion` 是 `-ion` 的最常见变体形式。

---

## 📝 使用条件

**何时使用此变体**：大多数动词，特别是以 **-te** 结尾的动词

- **使用场景**：绝大多数情况
- **拼写规则**：以 -te 结尾的动词，去掉 e 加 -tion
- **记忆技巧**：这是最常见的名词后缀形式

> [!tip] 拼写规律
> ```
> 动词以 -te 结尾 → 去掉 e + -tion
>
> create → creat + ion = creation
> invent → inven + ion = invention
> act → act + ion = action
> ```
