# -ion 后缀

## 基本信息

- **来源**: 拉丁语 **-ionem** (名词后缀)
- **类型**: 名词后缀 (noun suffix)
- **功能**: 将动词变成名词
- **频率**: **英语最高产的名词后缀之一！**
- **发音**: /ʃn/ (三种形式发音相同)

> [!tip] 核心功能
> **动词 + 后缀 = 名词**
>
> 表示：动作的结果、状态、过程

---

## 🔤 三种形式的区别

### 形式对比

| 后缀形式 | 使用条件 | 示例 |
|:---------|----------|------|
| [[\-tion]] | 最常见形式 | action, creation, invention |
| [[\-sion]] | 特殊情况（见下文） | permission, decision, expansion |
| **-ion** | 直接加在词根后 | opinion, union, region |

> [!info] 发音提示
> ```
> 三种形式发音完全相同：/ʃn/
>
> -tion: /ʃn/  (action)
> -sion: /ʃn/  (permission)
> -ion:  /ʃn/  (opinion)
> ```

---

## 📝 何时使用哪种形式？

### 1️⃣ **-tion** - 最常见

**适用情况**：大多数动词，特别是以 -te 结尾的动词

| 动词 | + -tion | 名词 | 含义 |
|:-----|:--------|------|------|
| act | → | **action** | 行动 |
| create | → | **creation** | 创造 |
| invent | → | **invention** | 发明 |
| collect | → | **collection** | 收集 |
| connect | → | **connection** | 连接 |
| protect | → | **protection** | 保护 |
| correct | → | **correction** | 纠正 |
| direct | → | **direction** | 方向 |
| select | → | **selection** | 选择 |
| suggest | → | **suggestion** | 建议 |
| react | → | **reaction** | 反应 |
| construct | → | **construction** | 建造 |
| educate | → | **education** | 教育 |
| decorate | → | **decoration** | 装饰 |
| translate | → | **translation** | 翻译 |
| operate | → | **operation** | 操作 |

> [!tip] 记忆规律
> ```
> 以 -te 结尾的动词 → 去掉 e + -tion
>
> create → creat + ion = creation
> invent → inven + ion = invention
> ```

### 3️⃣ **-ion** - 直接加词根

**适用情况**：直接加在词根后，通常词根不以 t/d 结尾

| 词根 | + -ion | 名词 | 含义 |
|:-----|:-------|------|------|
| opin | → | **opinion** | 意见 |

| reg | → | **region** | 地区 |
| sect | → | **section** | 部分 |
| pass | → | **passion** | 激情 |
| act | → | **action** | 行动 |

## 🎯 判断技巧总结

### 快速判断流程图

```
遇到动词要变名词？

1. 词根是 mit-/miss-？
   ✓ 是 → [[\-sion]] (permission, admission)
   ✗ 否 → 继续

2. 以 -d/-de 结尾？
   ✓ 是 → [[\-sion]] (decision, division)
   ✗ 否 → 继续

3. 以 -te 结尾？
   ✓ 是 → 去掉 e + [[\-tion]] (create → creation)
   ✗ 否 → 继续

4. 其他情况
   → [[\-tion]] (最常见)
   → -ion (直接加词根)
```

### 判断表

| 条件 | 后缀 | 示例 |
|:-----|------|------|
| mit-/miss- 词根 | [[\-sion]] | permission |
| 以 -d/-de 结尾 | [[\-sion]] | decision |
| 以 -te 结尾 | [[\-tion]] | creation |
| 直接加词根 | **-ion** | opinion |
| 其他情况 | [[\-tion]] | action |

## 🔊 发音规律

### 重音前移规律（最重要！）

**规律**：动词变成 -ion 名词时，**重音总是向前移动**

| 动词 | 名词 | 重音变化 |
|:-----|------|----------|
| per**MIT** (/pəˈmɪt/) | per**MIS**sion (/pəˈmɪʃn/) | 重音前移 |
| de**CIDE** (/dɪˈsaɪd/) | de**CI**sion (/dɪˈsɪʒn/) | 重音前移 |
| trans**MIT** (/trænsˈmɪt/) | trans**MIS**sion (/trænsˈmɪʃn/) | 重音前移 |
| ex**TEND** (/ɪkˈstend/) | ex**TEN**sion (/ɪkˈstenʃn/) | 重音前移 |
| ob**JECT** (/əbˈdʒekt/) | ob**JEC**tion (/əbˈdʒekʃn/) | 重音前移 |
| re**LAX** (/rɪˈlæks/) | re**LAX**ation (/ˌriːlækˈseɪʃn/) | 重音前移 |

> [!tip] 记忆要点
> ```
> 动词：重音在后面（通常倒数第二个音节）
> 名词：重音移到前面（通常倒数第三个音节）
>
> conDUCT  → conDUCTion  ❌
> conDUCT  → conDUCTion  ✓ (重音前移)
> ```
